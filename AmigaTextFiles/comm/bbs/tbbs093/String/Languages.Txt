The Internal language included in this directory is a list of the strings
used as a default by TechnoBBS (separated by CTRL-A codes).  This file is
never actually loaded (this wouldn't make sense, since it only contains
copies of the strings that are also in the actual executable), it is just
included so that you can copy it to files by different names and edit the
strings (to change the language used), which will enable users to use a
language that they can select (if you allow them) or you can set a
different language than the internal as a default.  If any string is empty
(0 characters long) or not included in the file the internal string for
this will be used.

If you translate these to some language (so that it doesn't sound silly),
you might want to send it to me so I can include it with the distribution.

Good translations are difficult to make, though, my attempt to translate
the strings to finnish ended up as a very confusing set of strings and due
to that there are no extra languages included with the distribution (not
yet, anyhow).

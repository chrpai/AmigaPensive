ConfLeft.TXT
============

This file is displayed after a user has leaves a conference.

It is NOT displayed when a user logs off.

It is ONLY displayed when they join another conference.

If a user selects J (for JOIN conf) at the menu, and then does not select
a different conference it will not be displayed.

You are now leaving the @^LastConf@ Conference

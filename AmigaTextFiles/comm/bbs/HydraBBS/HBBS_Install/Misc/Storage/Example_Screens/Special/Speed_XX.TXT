Speed_XX.TXT
============

Where XX is replaced with a baudrate, Eg. Speed_14400.TXT

There should be one of these files for each baud rate that you want a special file
displayed to.

So, if you wanted a special file displayed to all your users who connected at
28800 baud then create a file called Speed_28800.TXT

This file is displayed AFTER bbstitle.txt and BEFORE LoginLogo.TXT

@^@@^CLS^@Conf_BOT.TXT
============

This screen is displayed by the conference join door (J at the BBS
command prompt) when the user has not specified a conference to join.

This file is used by doors in different ways:

OldJoinConference will display this file only if the user has no other
conferences to choose from (because of access reasons)

JoinConference will display this file right after Conf_TOP and the
list of conferences to choose from have been displayed, regardless of
access.

See also Conf_TOP.TXT

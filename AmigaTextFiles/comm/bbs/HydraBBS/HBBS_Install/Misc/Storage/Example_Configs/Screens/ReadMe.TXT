HBBS:Screens
============

The following subdirectories are used by the system

Special
Users
Bulletins

The directory Misc is used by the example scripts and configs to store
some system generated screens (like charts and lastcallers etc..)

Tips:
=====

Only actually have system screens (like BBSTitle.TXT, LOGOFF.TXT etc..)
in the "Special" subdirectory and have all your screens for stuff like
last callers, top uppers, and so in in a seperate directory (I use "misc")
and use a screen command from the system screens to display them.  This
results in a much tidier BBS System and keeps everything in the right place..

User
====

if you have a file in this directory that's called the same as the user's
handle (+ the language extension) (E.G. Hydra.TXT) then it will be displayed
when they log on! (Cool Huh?)

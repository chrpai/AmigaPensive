Program     :  AmiExpress FileList to HBBS Filelist convertor.

Filename    :  AX2HBBS
Usage       :  AX2HBBS infile outfile [Year Prefix(2 characters only) e.g. 19]
            :          where infile is an AmiExpress Filelist
            :                outfile is the file to be creates
            :                        or an existing file for data to be
            :                        appended to.

==========================================================================


Simple External Program to show the contents of various list structures
within HBBS,  Currently Supported Lists are:
Nodes, Drives, Protocols, LanguageName/Extn, Conferences, Access Names,
Access Levels.

More to come,  this is really a development tool but I included it in the
HBBS archive as you might find it usefull.


Limitaitons
===========

Can only be run when Control in running.

Does not update automatically.

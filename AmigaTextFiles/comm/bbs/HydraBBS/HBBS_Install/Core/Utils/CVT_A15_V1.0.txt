CVT_A15_V1.0 by Dominic Clifton

This util converts HydraBBS Alpha Release 15 user.data files to
HydraBBS V1.0 user.data files

Do not attempt to run HydraBBS V1.0 with an A15 user.data file please.

The user.data file is located in HBBS:System/Data/User.data by default
unless you specified another location using the option in BBSGlobal

example usage.

7.dh1:HBBS> cd system/data
7.dh1:HBBS/System/Data> list user#?
Users                        Dir ----rwed 15-Oct-97 14:30:43
user.data                  13986 ----rwed Today     11:43:29
user.data.blank            empty ----rwed 22-Aug-97 20:14:44
2 files - 1 directory - 33 blocks used
7.dh1:HBBS/System/Data> copy user.data user.data_a15
7.dh1:HBBS/System/Data> delete user.data
user.data  Deleted
7.dh1:HBBS/System/Data> HBBS:Utils/CVT_A15_V1.0 user.data_a15 user.data
7.dh1:HBBS/System/Data> list user.#?
user.data.blank            empty ----rwed 22-Aug-97 20:14:44
user.data_a15              13986 ----rwed Today     11:44:27
user.data                  14634 ----rwed Today     11:44:54
3 files - 61 blocks used
7.dh1:HBBS/System/Data>


those commands again:

cd hbbs:
cd system/data
list user.#?
copy user.data user.data_a15
delete user.data
HBBS:Utils/CVT_A15_V1.0 user.data_a15 user.data
list user.#?

easy enough really..

Also note that this routine can be used for the basis of an /X to HBBS user.data file
converter if anyone feels like writing one!

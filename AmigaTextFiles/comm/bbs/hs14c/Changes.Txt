Changes:
v1.4c
- CNet problem fixed by Alan Bland.  There seems to be a problem with using
  SAS's rawcon() function w/CNet.  I had tried using another method, but it
  didn't work under SAS 6.  Alan fixed it to work.
- Just to be on the safe side, the new raw code is optional.  -r uses the
  new mode.  Default is to use rawcon().  Please try it with the -r, and let
  me know if it breaks so I know if it's safe to remove in a future version.
- Added a usage guide.  Calling H&S with an invalid argument, or bad args
  will display a list of options.
- Added a -t option to allow passing of time remaining on BBS.
  If BBSTime is less than GameTime, BBSTime is used.  The user is kicked out
  of the game 2 minutes before being logged off the BBS.
- Note the TAG bbs option is now -T.
- Also note that options are now case sensative.
- Changed the O option in the hints section to * to fix conflict when using
  hotkeys.

- Added support for TAG BBS (-t).

v1.3a 8-20-92
-Made the back-to-back call restriction optional.  if the ENV variable
 RPGCALLBACK is set, users will be unable to play until another person
 plays.  If it is not set, the game will play as it did before.  This
 also allows you to easily toggle this feature via a cron event so that
 during slow times of the day, you can turn it off, and turn it back on
 when you have alot of callers.
-Fixed the Experience display.
-Changed the display of large numbers so that it doesn't use scientific
 notation anymore.  (I think)

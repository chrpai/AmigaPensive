Welcome to Zeus 1.7!
--------------------

This release comes after several years and in response to ever growing
support.

This is the full install archive. It contains the complete Zeus program
and utilities, and requires only your personal keyfile to be complete.

It can also be used to upgrade an existing installation.

To do a fresh install
---------------------

To install, either click on the Install icon or execute it from
the shell.

To upgrade, backup your installation then start the installer. This works
with Zeus 1.5 and 1.6 only. The upgrade will keep your existing
configurations.

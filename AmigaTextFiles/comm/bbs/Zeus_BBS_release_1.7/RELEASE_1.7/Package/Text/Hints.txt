
                              Zeus User Hints
                             ~~~~~~~~~~~~~~~~~
New for 01-Feb-95

               -= Simple tips if you didn't know already =-

- When logging on, you can enter your alias instead of your real name.

- You can break a global file area search by pressing any key.

- The Hydra file transfer protocol allows you to upload and download at the
  same time.  If you run the latest version of TERM you should already be
  setup to use it.  If you run NCOMM then download file 42 (NCOMMHYDRA.LHA)

- If you upload an archive which has a file called FILE_ID.DIZ in it, that
  will be used for the file description and you won't have to type one in.

                        -= Command line editing =-

When at most menu prompts (and in some doors) you can edit the command line
using the following keys:

Back Space         - Delete character to the left of the cursor.
Ctrl-K             - Delete all data entered.
Delete Key         - Delete the character under the cursor.
Cursor Left        - Move the cursor left.
Cursor Right       - Move the cursor right.
Shift Cursor Left  - Position cursor at beginning of line.
Shift Cursor Right - Position cursor at end of line.
Ctrl-O             - Position cursor at the beginning of previous word.
Ctrl-P             - Position cursor at the beginning of next word.

These keys work even when you have ANSI codes turned off.


                          -= Command Stacking =-

If you do not use hot keys then you'll be able to use Command Stacking.
Commands can be stacked by putting a space or a semi-colon (;) between
them.  So for example if you were at the main menu you could enter f;a;1 to
jump to the file menu and change to area 1.

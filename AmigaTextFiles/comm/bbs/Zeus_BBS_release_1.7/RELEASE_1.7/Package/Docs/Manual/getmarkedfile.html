NAME
       GetMarkedFile

   SYNOPSIS
       GetMarkedFile <FIRST | LAST | NEXT | PREVIOUS>

   FUNCTION
       Traverse the current users list of marked files.
       If a marked file is correctly loaded, its information
       can be displayed using the CC file commands (%10xx|).

   INPUTS
       FIRST    -- Find the first marked file.
       LAST     -- Find the last marked file.
       NEXT     -- Move to the next marked file.
       PREVIOUS -- Move to the previous marked file.

   RESULT

   RC
       0 -- Got the marked file.
       5 -- No more files in marked list.

NAME
       Online -- Test if the modem is online or not

   SYNOPSIS
       Online

   FUNCTION
       This command is used to see if the phone line is active or not.
       It does not necessarily show if a valid call or session is in
       progress, just that the line is NOT clear. It therefore returns
       Online if ZMailer is dialling, in a Fido session, in a BBS
       session or waiting for a session to start (the "Press Escape"
       prompt).

   INPUTS

   RESULT
       "Online"  -- online
       "Offline" -- offline

   RC
       0 -- offline
       1 -- online

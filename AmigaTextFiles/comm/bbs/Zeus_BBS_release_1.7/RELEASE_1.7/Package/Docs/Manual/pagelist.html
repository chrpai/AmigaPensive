NAME
       PageList

   SYNOPSIS
       PageList [JUMP] [CONTINUOUS] [AGAIN]

   FUNCTION
       Outputs a file list, as defined by the folling Language
       strings:

       FILEFORMAT:
       SCANAREAS:
       FIRSTFILE:
       STDINDENT:
       STDFILENAME:

       SHORTLIST:
       ENDLIST:

       See the example languages and CC codes (which may be embedded
       in these strings) for more information.

       Before calling PageList, you must first initalise the file list
       system using SimpleList. Don't forget to
       free the memory used by this command by using EndList after
       using it.

   INPUTS
       JUMP        -- move to next file area
       CONTINUOUS  -- list files without stopping
       AGAIN       -- currently unimplemented

   RESULT

   RC
       0 -- Finished.
       1 -- End of page. Call PageList again to continue after
            handling the 'full page' prompt.
       2 -- Done all (wanted) files in area.
       3 -- In continuous mode, user broke output by pressing a key.

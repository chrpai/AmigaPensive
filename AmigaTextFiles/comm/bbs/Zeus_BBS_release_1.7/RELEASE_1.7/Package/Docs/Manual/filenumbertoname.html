NAME
       FilenumberToName

   SYNOPSIS
       FilenumberToName <NUM>

   FUNCTION
       Converts a given file number into the file's name.

   INPUTS
       NUM -- Number of file to find.

   RESULT
       Name of file.

   RC
        0 -- Successful
        5 -- No such file
       10 -- Bad arguments

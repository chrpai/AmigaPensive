NAME
       WriteMsg -- Saves to disk a new message.

   SYNOPSIS
       WriteMsg [NOREFLOW] [NOEXE] <FileName>

   FUNCTION
       Completes writing a message by finally saving the data to the
       message base.  The message data (To, From, area etc.) is set using
       SetMsgData calls.  After they have
       been performed, WriteMsg is called specifying the actual message
       text file.

   INPUTS
       [NOREFLOW] -- Optionally, do not process the message by
                     reformatting it into paragraphs.
       [NOEXE]    -- Disable running any Area Executable which
                     may be set on the specified area.
       <FileName> -- File containing the message body.

   RESULT

   RC
        0 -- Successful.
        2 -- Failed to set previous message's `reply' information.
        5 -- Couldn't open <FileName>, does it exist?
       10 -- Couldn't find specified message area.
       15 -- Failed to write message to the message base.
       20 -- Failure. Vital Zeus data missing or out of memory.

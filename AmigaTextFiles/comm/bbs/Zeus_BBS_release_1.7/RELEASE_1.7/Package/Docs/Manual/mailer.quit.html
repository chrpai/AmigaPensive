NAME
       Quit

   SYNOPSIS
       Quit

   FUNCTION
       Quits ZMailer.

       This command may fail if ZMailer is currently in a mail or BBS
       session. It is recommended that your ARexx contains a loop in
       which is checks with FindPort for the ZMailer ARexx port, and
       sents Quit every few seconds until ZMailer does quit.

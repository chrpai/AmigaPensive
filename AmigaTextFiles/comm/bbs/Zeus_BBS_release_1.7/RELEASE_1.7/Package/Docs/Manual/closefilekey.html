NAME
       CloseFileKey

   SYNOPSIS
       CloseFileKey <KEY>

   FUNCTION
       Close and deallocate resources taken by a file key
       initialised with InitFileKey.

   INPUTS
       KEY -- Key are returned by InitFileKey

   RESULT

   RC
       0 -- Successful

   EXAMPLE

   NOTES
          Asynchronous

       InitFileKey GetFileFromKey

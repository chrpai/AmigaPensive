NAME
       FileRequest

   SYNOPSIS
       FileRequest '"<COMMAND>"'

   FUNCTION
       Program to run when a file request is detected.

       File requests are files with the extension ".REQ" which contain
       lists of files they want to download from your BBS. A File
       Request (or FReq) processor is needed to take care of these
       files. See the ZMailer section in the Lines chapter of the Zeus
       manual for more information, and for the special codes which
       can be placed in the command line.

   INPUTS
       COMMAND -- Command to run

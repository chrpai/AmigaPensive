NAME
                MaskMsgArea -- Controls masking information for a message area.

   SYNOPSIS
                MaskMsgArea [AREA <Area Number>] <MASKIN|MASKOUT|TOGGLE> [SIG] [ALL]

   FUNCTION
                Determines whether the user is notified about
                personal messages a given area.

   INPUTS

   RESULT

   RC
                 0 -- Message masked
                 2 -- Message areas 
                10 -- Bad arguments
                20 -- Fatal error

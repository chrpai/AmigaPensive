Rexx Directory

This contains many ARexx programs which complement Zeus BBS.

These programs are not required to run Zeus, the purpose of them is to make running Zeus easier. Some of the programs included are:

. ZAmiNet - A program to facilitate turning your BBS (or a section or SIG of it) into an AmiNet mirror.
. Config
. FileAreas
. MessageAreas - These are some programs to allow you to configure parts of Zeus with the Prefs/ directory programs, and without using ARexx. Studying these programs might give you an insight into ARexx which could help you develop powerful, automated configuration scripts!

NAME
       FindMsgAreaTag -- Returns the area number of a given Fido style echo tag.

   SYNOPSIS
       FindMsgAreaTag <TAGNAME>

   FUNCTION
       Returns the message area number of an area with the given Fidonet type
       echo name (Tag).

   INPUTS
       TAGNAME -- Area to find

   RESULT
       Area number if found.

   RC
        0 -- Found, message area number is in return
        5 -- Bad arguments
       10 -- Area does not exist

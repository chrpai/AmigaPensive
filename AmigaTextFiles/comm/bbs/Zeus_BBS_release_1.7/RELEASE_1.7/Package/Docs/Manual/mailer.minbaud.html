NAME
       MinBaud

   SYNOPSIS
       MinBaud BAUD

   FUNCTION
       Temporarily (until ZMailer is quit or this command is called
       again) set the minimum baud rate at which to allow connections.

       If the baud rate at which a user connects is lower than this,
       they will be notified and the ZMailer will hang up.

   INPUTS
       BAUD -- Bits/s rate

   RESULT

   RC

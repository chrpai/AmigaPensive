NAME
       InitMsgScan -- Initialises a fast message header scan (v1.6)

   SYNOPSIS
       InitMsgScan [AREA <Area Number>] [FORWARD|BACKWARD] [STARTMSG
                   <Message Number>]

   FUNCTION
       Zeus's message control features a fast, buffered message scanning
       engine which should allow rapid generation of lists such as when
       scanning a message header's headers. This was binary only until
       Zeus 1.6, when an ARexx interface was added to the API.

       This function initialises the scan with the basic details you are
       looking to extract messages with. It also respects the message
       filtering API.

       You then obtain message data by calling MsgScan repeatedly.

       At the end, you must call EndMsgScan to deallocate the resources
       that this call allocates.

   INPUTS
       [AREA]     -- Optionally, the area to scan, else the user's
                     current area.
       [FORWARD]  -- Scan messages forwards, 1..100..
       [BACKWARD] -- Scan messages backwards, ..100..1
       [STARTMSG] -- Optionally scan messages from a given point. If
                     not specified, then:
                       if forwards, start from message 1.
                       if backwards, start from the last message.

   RESULT

   RC
        0 -- Successful.
       10 -- Incorrect arguments.
       20 -- Failure.

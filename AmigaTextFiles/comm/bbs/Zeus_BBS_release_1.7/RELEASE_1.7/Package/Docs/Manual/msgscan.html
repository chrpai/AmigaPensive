NAME
       MsgScan -- Fast, buffered scan through message headers (v1.6)

   SYNOPSIS
       MsgScan

   FUNCTION
       See also InitScanMsg.

       Sets the user's current message to the next in a message header
       scanning session.

   INPUTS

   RESULT

   RC
                 0 -- Message loaded
                 1 -- Message did not match filter
                 2 -- Could not load message
                 3 -- User may not read message
                 4 -- Message does no longer exist
                 5 -- SCAN COMPLETED
                20 -- Fatal error

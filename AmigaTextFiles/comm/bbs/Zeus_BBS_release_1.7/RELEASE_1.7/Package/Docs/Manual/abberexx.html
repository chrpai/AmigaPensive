NAME

       CliDoor '"Abberexx"' -- Runs an Abberexx door.

   SYNOPSIS

       CliDoor '"Abberexx 'LINE/A' TYPE/K DOOR/A/F"'

   FUNCTION

       This is an interface to run Abberexx doors. This isn't
       actually an ARexx command, the interface for Abberexx
       is external to Zeus.

   INPUTS

       Line    -    Using the standard Zeus scripts, simply pass
                    this as Line. In Zeus, line is filled with
                    the line the command was executed from.

       Type    -    Since there are some variations in the
                    implementation of Abberexx interfaces in other
                    BBS packages, this allows you to set the
                    subtle differences necessary for them.

                    Type=CNET  for CNet doors.
                    Type=XLK   for XenoLink doors.

                    or, don't include a Type for standard
                    Abberexx, as used by TransAmiga, for example.

   RESULT

   RC

   EXAMPLE

       CLIDoor '"ABBERexx 'Line' TYPE=CNET EL.PD"'

       CLIDoor '"ABBERexx 'Line' TYPE=XLK Assassin/Assassin.trans 'Line'"'

   NOTES

       IMPORTANT: When you call an ABBEREXX script, you cannot
       access any of Zeus's ARexx commands. This may seem like a
       problem, but since the idea of ABBEREXX is to make BBS
       scripts portable, it does make sense.  You should not use
       Zeus ARexx commands in ABBEREXX scripts (or if you do,
       do a check for the ZEUS port and provide if not found

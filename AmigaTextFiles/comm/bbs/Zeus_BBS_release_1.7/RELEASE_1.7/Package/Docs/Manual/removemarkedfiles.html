NAME
       RemoveMarkedFiles

   SYNOPSIS
       RemoveMarkedFiles [ALL]|[FILENAME <FileName>]|[NUMBER <Number>]

   FUNCTION
       Removes marks on files.

   INPUTS
       ALL      -- Remove all marks for current user.
       FileName -- Remove specified file by name
       Number   -- Remove specified file by number

   RESULT

   RC
        0 -- Successful
        5 -- File not marked
       10 -- Bad arguments

   EXAMPLE
       RemoveMarkedFiles ALL
       RemoveMarkedFiles FILENAME '"Old.lzx"'
       RemoveMarkedFiles NUMBER '"100"'

NAME
       Call

   SYNOPSIS
       Call <Number|FidoNet Address> [NOEMSI]

   FUNCTION
       Calls the number or address specified.  ZMailer will attempt to
       call the given number, if busy, the number of times specified
       in ZMailer preferences.

       Some older FidoNet mailers which do no support the EMSI mailer
       standard do not correctly refuse it; such as MAX's BBS. To call
       a system which behaves like this, specify the NoEMSI argument.
       ZMailer will drop, for this call only, to the FTS-1 (LoTek) or
       WaZoo protocol for negotiation. The disadvantage of doing this
       is that these protocols present only one address. The address
       shown in these cases is the first one with the same Zone number
       as the address you are calling, or if you have specified a
       phone number the very first address in the list.

       If a call is currently in progress, any further calls will be
       queued. You can view the list of queued calls with the user
       interface of ZMailer 1.2 and higher versions. If a number is
       busy, ZMailer will move to the next call in the list and
       progress through each until a connect is achieved. If a call
       connects, that entry in the queue will be removed after the
       call is finished and ZMailer will then continue down the queue
       list.

   INPUTS
       <Number|FidoNet Address>     -- number to call.
       [NOEMSI]                     -- Disable EMSI for this call.

   RESULT
        0 -- Successful
       10 -- Unknown number/address

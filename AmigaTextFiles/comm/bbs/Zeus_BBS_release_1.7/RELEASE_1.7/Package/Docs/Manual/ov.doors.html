Doors Directory

These are the programs which run over your BBS for users to use. You may need to alter configurations in here from some doors.

Doors can be of several types:

ZDoors - special executable programs specifically for Zeus.
CLI - any command line interface (shell) program can be launched to run over the BBS.
Generic ARexx - run just like any ARexx script, like a shell program.
Zeus ARexx - an ARexx script which is run exactly like a script from the Zeus scriptset.

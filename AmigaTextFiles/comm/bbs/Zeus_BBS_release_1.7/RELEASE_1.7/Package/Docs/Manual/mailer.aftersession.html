NAME
       AfterSession

   SYNOPSIS
       AfterSession '"<COMMAND>"'

   FUNCTION
       Set the after session command of ZMailer to the string given.
       This will be reset to the one stored in the preferences
       when ZMailer is quit and and reloaded.

   INPUTS
       COMMAND - the command string to execute after a session.

   RESULT

   RC

NAME
      PnxRemConfig

   SYNOPSIS
      PnxRemConfig

   FUNCTION
      Will delete the user's Phoenix configuration.

   NOTES
      To remove the area configuration you can use "PnxMaskArea RemAll".

   INPUTS

   RESULT
      RC  0 - Configuration found and removed.
      RC 10 - Couldn't find the configuration (It's allready removed).

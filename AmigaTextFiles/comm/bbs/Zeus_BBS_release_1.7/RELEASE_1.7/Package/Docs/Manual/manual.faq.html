Appendix D

Frequently Asked Questions

Q ZMP - I cannot import file attaches if they have a .TIC or .MO0, etc., file extension.

A These file extensions are usually reserved for FidoNet bundles and tick echoes. ZMP ignores these files incase they are supposed to be imported normally. Some packages for the PC actually attach Tick data files to netmails, and if Zeus were to import this as an attachment then the Tick would not be processed!


Q I am no good at ARexx or programming, what can I do?

A You don't need to alter the Zeus ScriptSet. If you are happy with the provided scripts, then you don't need to change them. If you really wish to change something, ask for assistance in ZeusNet. If you're lucky somebody may be available to perform the change for you.


Q My modem reports CONNECT strings like:
CONNECT 57600/V34/LAPM/V42BIS/28800:TX/31200:RX
where 57600 is only my computer to modem speed. Does Zeus correctly detect this? Or can I change my modem's results?

A Zeus takes the receiving speed (":RX") of such strings. You can change how the modem reports the speed, but with V90 modems it's often not a good idea. At least, my modem is incapable of any decend speed report which includes modem to modem and compression information. Remember that many other programs you could use to answer the 'phone will most likely still take the modem speed as being 57600.


Q ZMailer doesn't seem to load at all.

A ZMailer must have a working Nodelist installation, using the TrapList library. In addition to this, you must have "Nodelist:" assigned to the directory holding the nodelist's data.


Q My system crashed while ZMP was running, and although it finished importing (it was in the export phase) none of the messages are on the BBS!

A The new high message number wasn't written to disk - run "mbmanager update all" to fix this, then run "zmp export" to finish the mail run.


Q When dialling out using a TelSer node and ZMailer, TelSer always reports that the IP or name address is wrong, even though I can telnet and ping to it. Why?

A The most likely reason is that ZMailer is sending the dial command to TelSer as "ATD<host>". TelSer doesn't like this, it requires "ATD <host>" with space. To fix this, simply open ZMailer Preferences from Control, and for your TelSer nodes set the dial command to "ATD ", with the extra space at the end.

NAME
       NextUserKey -- Gets the next user in the list.

   SYNOPSIS
       NextUserKey <UserKey>

   FUNCTION
       Gets the next userkey in the direction specified with InitUserKey.
       
   INPUTS
       UserKey - Pointer to a userkey as generated by InitUserKey.

    RC
        0 - Got next userkey.
        5 - No more users.
       10 - Bad arguments.


   EXAMPLE

   NOTES
          Asynchronous

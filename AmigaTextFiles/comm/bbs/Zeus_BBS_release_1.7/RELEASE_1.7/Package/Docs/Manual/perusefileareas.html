NAME
       PeruseFileAreas

   SYNOPSIS
       PeruseFileAreas <FIRST|LAST|NEXT|PREV>

   FUNCTION
       Determines whether a given area exists and it's number.

   INPUTS
       FIRST -- First area in global areas list
       LAST  -- Last area in global areas list
       NEXT  -- Next area
       PREV  -- Previous area

   RESULT
       Area number

   RC
       >0 -- Area does exist
        0 -- Ares does not exist

   EXAMPLE

   NOTES
          Asynchronous

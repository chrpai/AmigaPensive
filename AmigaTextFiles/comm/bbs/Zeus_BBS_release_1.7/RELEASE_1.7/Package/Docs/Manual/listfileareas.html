NAME
       ListFileAreas

   SYNOPSIS
       ListFileAreas [IGNORESIG]

   FUNCTION
       Builds a very simple two column list of file areas and
       sends the list directly to the output.

       Generally not much use as no colour is used and the
       output is not configurable.

   INPUTS
       IGNORESIG -- List all file areas, rather than
                    just the current SIG.

   RC

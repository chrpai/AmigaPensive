NAME
       MarkDOSFile

   SYNOPSIS
       MarkDOSFile <FILENAME> [CHECK]

   FUNCTION
       Adds a DOS file, not in Zeus' file catalogues, to the user's
       download list. This is potentially dangerous if a user is
       allowed to specify files to download themselves, as any file
       can specified including data and programs on your disks!

       Example uses for this function are:
        · on a SysOp only menu.
        · marking specific files for a user
          (e.g., you have a file list which for some reason isn't in
          the catalogue. The user presses "F" to call a part of your
          menu which marks the files directly).

   INPUTS
       FILENAME -- File to mark for download.
       CHECK    -- Check if file is already marked, and also check
                   the user's file/byte ratio has enough left to
                   download the file. This makes MarkDOSFile act
                   more like normal file marking for users.

   RESULT

   RC
        0 -- Successful
        1 -- Failed, file is zero bytes
        2 -- File already marked
        3 -- File/byte ratio left is insufficient to download file.
        5 -- Failed to add marked file to user's marked file list.
       10 -- Bad arguments

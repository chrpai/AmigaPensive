Chapter 17 - Phoenix: The Bluewave and QWK Door


Offline Reading

An offline reader is a program which allows users of your BBS to collect messages, archive them and download for reading while not online. It requires two programs: a client, the Offline reader program, and a server, the Offline reader door. The user of the BBS will use both of these programs, however the Offline reader door is, as the name suggests, a door on your BBS rather than a program on the user's machine.

The most popular Offline formats (there are several) allow users to reply to messages and send these replies back up to the BBS. Of these, there are two major ones which Zeus supports: Bluewave and QWK. Bluewave is the technically superior of the two, offering proper Netmail support (in which QWK is weak) and allowing the user to `fix' into areas while offline. With QWK, the user must request areas to download while online, or send messages to a specific name on the BBS in a similar way to a point using AreaFix.


Configuration

All the ScriptSets supplied with Zeus include the Phoenix scripts and default text files.

To open the Phoenix preferences program, either open it via Workbench in the Prefs drawer or select QWK/Bluewave from the Messages menu in Control.



BBS ID - A short unique name for your BBS (3-5 alphanumeric characters with no spaces). This in effect allows users to collect mail from many BBS's and keep the accounts seperate.

Phone no - The telephone number of your BBS.

Primary addr. - The main FidoNet-style address of your BBS.

Msgs Packet - The default maximum number of messages someone can receive in a packet. If you have a large BBS, use this to stop users accidentally requesting huge amounts of mail.

Area - Similar to the above, but set for each area requested not the whole packet.

Memory Usage - Phoenix uses buffers to speed up message grabbing. Set the size of the buffers here.




The first four are files which will be included with the grabbed mail for information purposes. The Work path is a path to store temporary files - it must be big enough to hold a decently sized download. Several megabytes at least.

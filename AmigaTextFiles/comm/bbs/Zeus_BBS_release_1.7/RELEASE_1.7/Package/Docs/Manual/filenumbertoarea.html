NAME
       FileNumberToArea

   SYNOPSIS
       FileNumberToArea <NUM>

   FUNCTION
       Returns the area number in which the specified file is in.

   INPUTS
       NUM -- File number to find.

   RESULT
       Number of area.

   RC
        0 -- Successful
        5 -- No such file
       10 -- Bad arguments

   EXAMPLE

   NOTES
          Asynchronous

       FilenameToNumber FilenumberToName

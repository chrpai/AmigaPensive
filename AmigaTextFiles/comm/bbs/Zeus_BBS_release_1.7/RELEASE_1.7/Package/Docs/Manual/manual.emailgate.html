Chapter 16 - FidoNet over E-Mail Tunnelling
or
How to `Gate' to FidoNet Nodes via. Internet E-Mail
===================================================

What FidoNet over e-mail tunnelling is

"Tunnelling" is a bit of jargon from the science of computer networking. It is the idea of carrying one type of network over another type which is incompatible. In our case, we want to send FidoNet over Internet e-mail. This is being increasingly done elsewhere, where the new Internet address system, IPv6, is being `tunnelled' over older systems which only support the current IPv4 (which is the "192.168.1.34" type of address).

Fidonet via e-mail is an area of Fidonet which is growing daily. While having the disadvantage of being an indirect way of transferring mail, Fidonet via e-mail provides a way to cheaply distribute networks over long distances, such as international links.

Zeus:Bin/EMailGate is a program which allows the sending of normal Fidonet mail (the finished bundles and packets you see in your Outbound directory) over e-mail which, once at the destination, can be decoded back into real Fidonet bundles and packets and imported.

Zeus does not current provide facilities for decoding mail, although this is easily done by running a uudecoder and MIME decoder over a specifically named mailbox, or by using a 3rd party mail packet such as YAM and its import mailbox feature. We will endeavour to expand Zeus BBS's features to include a purpose built decoder soon (one which will allow easy integration with shared mailboxes, if you only have a single e-mail address, for example).



Usage

EMailGate can either place tunnelled mail in the Spool directory (as defined by Zeus's Internet prefs), ready for sending with tools like SMTPpost from the INetUtils package (please see the script provided below) or Zeus's own ZSMTPXfer which is specifically designed for the task, or it can use PutMail by Martin Lanza to directly send mail to your Internet provider's servers without using an intermediate Spool file. PutMail is available on AmiNet.

If the mail is placed in Spool, then it is in a raw e-mail format. This is suitable for sending via any other means, either by importing directly into a package such as YAM or even processed by some ARexx for sending by any method at all. As mentioned, Zeus's own ZSMTPXfer is designed to deal with this.

If you wish to use PutMail, you should have a directory PutMail in AmiTCP: in which PutMail is place (i.e., "AmiTCP:PutMail/PutMail" is the executable). If you use Miami or another TCP/IP stack, you will have to assign AmiTCP: to your Miami directory and place the PutMail directory in there. This is a problem which will be readdressed.



Configuration

Edit Zeus:Config/EmailTunnel.cfg

The first line is an identification of the configuration being used, and is ideally used to put a short identifier to highlight that the messages being generated contain UUEncoded Fidonet-type mail. It is irrelevant as far as EMailGate is concerned.

To gate to three nodes, an example config might be: 

----------------cut-----------------
FIDONET
85:1/467.0   someone@address.com
85:1/543.0   another@hello.com   UUENCODE
2:1/344.0    another@blah.com    MIME
----------------cut-----------------


The format of each line is: 

<FTN address> <e-mail address> <encoding method>


(where FTN is Fido-Technology-Network, meaning anything using Fido software)

The encoding method allows you to send mail in either MIME Base64 or UUEncode formats. If you tunnel to a PC system, you might have to experiment to see which method will work, as some PC software used for tunnelling can be quite poor.

The default is UUEncode, and this is what you should use unless you have difficulties with it.


Load up Prefs/Archivers

Add a new archiver "UUENCODE"

Enter data for your UUEncoder (UUxt is recommended) so that `Compress' uuencodes data, and `Decompress' uudecodes data. Since this is useless to general BBS use, deselect `Show User'.

For example: 

   Name:      UUENCODE
   Compress:  c:uuxt a ~a ~f
   Extract:   c:uuxt x ~a
   Show User: NO


Leave the other fields blank.


Now add another new archiver, "MIMEENC"

This one will be used for encoding MIME data for EMailGate. There are many of these available on BBS's and AmiNet, I'll show you configurations for Base64Encoder and Base64: 

   Name:      MIMEENC
   Compress:  Base64Encode ~f ~a
   Extract:   Base64Decode ~a
   Show User: NO


or 

   Name:      MIMEENC
   Compress:  Base64 ~f ~a E
   Extract:   Base64 ~a D
   Show User: NO


The Base64Encode/Decode pack should come with Zeus in the 3rd Party Utils archive.

Leave the other fields blank.

Run "UpdateConfigs ARC" to update this.


Using PUTMAIL:

To use PutMail, include the PUTMAIL argument when running the program.

My email address for Fidonet is "fido@tkgbbs.freeserve.co.uk" and my SMTPHOST (the server to which I send e-mail) is "smtp.freeserve.co.uk" so I would use the following command line. 

   Run Zeus:Bin/EMailGate CONFIGFILE Zeus:Config/EmailTunnel.cfg MAILADDRESS fido@tkgbbs.freeserve.co.uk SMTPHOST smtp.freeserve.co.uk ARCHIVER UUENCODE PUTMAIL COPYOLD


Demon configurations might use (for example): 

Run Zeus:Bin/EMailGate CONFIGFILE Zeus:Config/EmailTunnel.cfg MAILADDRESS zeusnet@bleach.demon.co.uk SMTPHOST post.demon.co.uk ARCHIVER UUENCODE COPYOLD PUTMAIL



Using Spool:

To spool mail to your configured Spool directory (often "UUSpool:"), simply leave off the PutMail argument. You must still include all the details for address and SMTP host however. 

Run Zeus:Bin/EMailGate CONFIGFILE Zeus:Config/EmailTunnel.cfg MAILADDRESS fido@tkgbbs.freeserve.co.uk SMTPHOST smtp.freeserve.co.uk ARCHIVER UUENCODE COPYOLD


This will leave files in Spool which can be sent using SMTPpost (from the INetUtils package on AmiNet) using a script such as: 

------------ cut -------------------
; Send queue mail via SMTP

pcd uuspool:
List >T:SendMailQueue.temp D.#? lformat "SMTPPost -S %n*Nif not error*N delete %n*N delete X.%e*Nendif*N"
Execute T:SendMailQueue.temp
Delete T:SendMailQueue.temp
pcd
------------ cut -------------------


Or by running ZSMTPXfer on the directory, or processed however you wish.


COPYOLD Argument

This argument, on the command line, will copy mail which has been sent into a directory called "Old" in your outbound directory. Should something go wrong and the mail is not delivered, you can resend it manually from here.

However no check is kept on the amount of mail kept in this directory, so it is up to you as SysOp to periodically clean it, perhaps on a Cron job.


ARCHIVER argument

From Zeus 1.3, the two `archivers' used are named UUEncode and MimeEnc. MimeEnc is fixed, and cannot be changed; if you wish to use a different archiver name for the UUEncode program, it can be specified using this argument.

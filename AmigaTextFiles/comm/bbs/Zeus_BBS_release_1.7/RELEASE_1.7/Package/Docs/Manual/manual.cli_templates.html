Appendix C

Command Line Interface Templates

Although this is covered in the AmigaDOS manual, for those who don't own a copy here is some information essential to using Zeus effectively (while the DOS manual isn't included with some Amiga computers, all copies of OS 3.5 include it in HTML and PDF format).

When using the Zeus command line tools, you'll see templates such as this when you run the program with no arguments (or with arguments of "?"): 

Usage: PostMsg FROM/A,TO/A,SUBJECT/A,TEXTFILE/A,AREA/N,ADDRESS,PRIVATE/S,NOWRAP/S,TAG/K

   FROM         - Author of message
   TO           - Message recipient
   SUBJECT      - Message topic
   TEXTFILE     - File to retrieve message text from
   AREA         - Area number to save message in
   ADDRESS      - Destination FidoNet address (netmails)
   PRIVATE      - Mark message as private
   NOWRAP       - Don't wrap message lines
   TAG          - If AREA is not given, this Fido Echo name will be looked up.


The table is displayed by the Zeus tools themselves to give verbose descriptions. The template, however, is the long capitalised line near the top. This is used by the Amiga Operating System to provide a uniform and powerful interface to all Amiga command line programs. As such the same sort of things are seen in almost all Amiga programs runable from the Shell prompt.

At the end of each argument (i.e. each element you can input) there is a slash "/" followed by a single character, followed either by another slash and character or a comma which indicates another argument option is starting. The character after the slash tells you exactly how the argument behaves:

/A -- This is a required argument. It must be given for the command to run.

/S -- This is a switch. If provided by entering its name in full, you will turn that item on.

/K -- A "keyword". These are used to remove any ambiguity by requiring you to enter both the argument name and the option you want. For example, for TAG/K you must enter "TAG=name". You can omit the equals sign, but your data must follow the keyword.

/N -- A number. Only a number is acceptable for this option.

/F -- The full command line. This means that everything entered after this argument is taken as being part of this argument, whether there are spaces or not.

/M -- Multiple strings, not used much in Zeus. It means you can enter more than one item for this argument, similar to /F but other options such as switches can be included.

/T -- Toggle. Rarely used, since a switch performs a simiar function. This can toggle an option on and off each time a program is run, but the program must save the previous setting.


Often you will want to include an option which contains a space, such as the above example for the PostMsg command where the From argument might be Fred Bloggs, for example. To do this, simply enclose the option in double quotes: "Fred Bloggs".

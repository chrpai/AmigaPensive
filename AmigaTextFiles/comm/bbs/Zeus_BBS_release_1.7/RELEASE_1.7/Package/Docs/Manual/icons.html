Main Icons:

Two men talking/Ignoring each other:

This icon allows you to toggle whether you are available for paging.
When the men are ignoring each other it means you are not available. This
icon is created by a program called Utils/ChatStatus and the image is
taken from the file Zeus:Config/Icons/ChatStatus.info, which is a standard
icon file.

ZEUS icon with a line number underneath:

These icon(s) indicate that an ANSI watcher is loaded/iconified.
Clicking on one will pop up the watcher for the applicable line. If it
is a local line then pressing Return will log you into the BBS. A watcher
allows you to see what the remote user is doing, chat with them or
navigate them round your BBS.

FED (Filing cabinet and scissors)

This icon is created by Bin/ZeusDock, Zeus' internal Dock program
which is configured with the Prefs/DockCfg program. Pressing this icon
will execute Utils/FileEditor.

UED (Surgeon with patient)

This icon is also created by Bin/ZeusDock Pressing this icon will
execute Utils/UserEditor.

US style Mailbox

This icon is created with the Bin/PostMan program. The icon
images are taken from Zeus:Config/Icons/(No)Mail.info. This program
monitors the SysOp's mailbox (the SysOp name is taken from the IEMSI
Information settings as defined in Prefs/System and changes its
image when mail is written or imported for the SysOp.

Help button

Another ZeusDock icon. Loads this help file using Multiview on
the ZEUS screen. Configure the viewer by loading up Prefs/DockCfg,
selecting "Dock/Help" and changing the "Execute" string gadget.

Voyeur Icons:

Jack in the Box

"Pops" up the selected line. This will uniconify the watcher
selected, or launch a new one by calling the "Zeus:Rexx/PopUpWatcher"
script.

Boot

Boots the user on the selected line off the BBS. This will
terminate their call!

Puzzled Man

Shows pertinent information about the user currently selected.

Surgeon and Patient

Loads up "Utils/UserEditor" with the current user already
selected.

Broadcast Mast

Sends a "node message" to the user currently onlien.

Iconify

Iconifies "Utils/Voyeur" into a small icon on the control screen.
This icon is configurable from the file "Zeus:Config/Icons/Voyeur.info"

Appendix E

Glossary of BBS terms


A

Area - A section of your BBS which holds some kind of data: a file area or a message area for example.


B

Bulletin Board System (BBS) - What Zeus is as a whole; a system to provide services such as files, messages, games, and interactive chatrooms to people who connect to it, usually via a direct modem connection but increasingly via TelNet over the Internet.


C

Cron - A program which executes commands or scripts a set times of the day. A Cron program is usually very configurable in the times it can be set to execute commands, allowing you to set ranges of days, specific days, groups of hours or minutes, and much more. A freeware Cron program (proven to be extremely reliable) is supplied with Zeus in the 3rd party utilities archive, called "cRon". The Cron program originated on Unix systems so is usually configured via a text file.


D


E

Echo - The method by which FidoNet-type networks move data. Each BBS that receives a message (or file) will copy that data for itself, then produce copies (the data is "echoed") for other BBSs, which will repeat this. It also applies to a FidoNet area, as they are called "Echoes" after the method by which they are distributed.

Export - if an item is taken out of a collection of items for, e.g., sending to another computer, it has been exported. FidoNet messages written on your BBS will be exported by ZMP for collection of sending to other BBS's.


F

FileControl - The program which must be running for the Files sub-system of Zeus to be active. So, to upload, download or even just view file statistics, FileControl must be running. By default, Zeus launches it itself when starting, via the StartUp preferences.

FileConfig - A program in the Prefs/ drawer with which you define what file areas are on your BBS.


G


H

Hatch - When someone says that they `Hatch' a file, they mean they are putting a file and tick into a file/tick echo, and every BBS linked to that echo will get the file. See also: Tick


I

Import - Import means to put an item or items into a greater, often structured collection. For example, we say that we Import FidoNet messages into the Zeus message base, where they are separated out into areas/echoes for reading. See also: Export


J


K


L


M

MsgControl - The program which must be running for the Messages sub-system of Zeus to be active. So, to read, write or even just view messages statistics, MsgControl must be running. By default, Zeus launches it itself when starting, via the StartUp preferences.

MsgConfig - A program in the Prefs/ drawer with which you define what Messages areas are on your BBS. This does not define which areas are available from FidoNet or the Internet, that is done in conjunction with the Config/ZMP.cfg text preferences file.


N

NodeList - The phonebook of FidoNet or FidoNet-type networks. These special files contain lists of every node in that particular network, and are usually distributed by tick echoes.

S

Special Interest Group (SIG) - A division of your BBS into which a number of message and/or file areas are grouped, in order to break a large BBS into more manageable parts. See also: Areas


T

Tick - A tick is a small file (with the extension .TIC) which is sent along with files over FidoNet. The tick carries information about the file, such as what echo area it belongs to, where it came from, and what the description of the file is. A tick is used to move files around FidoNet-type networks, in exactly the same way as messages move around in echo areas. See also: Hatch

Tunnelling - Transmitting one type of network through a virtual `tunnel' in another type of network.

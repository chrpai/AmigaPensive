NAME
       SModem

   SYNOPSIS
       SModem <Command>

   FUNCTION
       Sends the modem command given to the modem if there is
       no user online (check with the Online command).

       An example for the use of this is switching the speaker on your
       modem off at night while you sleep, and on in the morning for
       you to monitor calls. This can be done on a Cron job using
       lines similar to:

       rx "address ZMailer.1;SModem 'ATM0'"

       rx "address ZMailer.1;SModem 'ATM1'"

   INPUTS
       Command -- Modem command to send.

   RESULT

   RC

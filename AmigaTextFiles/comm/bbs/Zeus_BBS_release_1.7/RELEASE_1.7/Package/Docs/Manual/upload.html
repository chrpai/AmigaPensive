NAME
       Upload

   SYNOPSIS
       Upload

   FUNCTION
       Begins an upload with the users selected file transfer protocol.

       When this is called, Zeus will start the upload protocol as
       specified by the current user. This command may not return
       control to your ScriptSet for some time, and when it does you
       should check for uploaded files and if necessary add those
       files to your file base.

       Before calling upload, you should check whether the current
       transfer protocol supports "Batch uploads" (see GetProtocolInfo
       'BATCH') - if not you will first need to request the name of
       the files being uploaded from the user. Add these names to the
       upload list using AddToUploadList.

   INPUTS

   RESULT

   RC
        0 -- Successful
        5 -- File protocol invalid
       10 -- No file protocol selected
       12 -- No upload directory present
       15 -- No files queued for upload, with a protocol which does
             not support Batch uploads.

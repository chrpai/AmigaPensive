  The AKA you send "From" will determine the File Bones or Echomail
  areas you can access.  If you collect several networks from this
  site, you need to send a message to ViaSERV from each of your AKAs
  to activate/Deactive the appropriate areas.
 
  Address your message to:

       ECHOSERV   to alter echomail selections, or
       ARCSERV    for Filebone conferences


  AVAILABLE COMMANDS
  컴컴컴컴컴컴컴컴컴

  SUB   - Select an echo or file echo.
  UNSUB - Deselect echo or file echo.
  GET   - Request information on....                                  
  SET   - Alter a setting....


  SET ARCFORMAT <format>     e.g. SET ARCFORMAT ZIP (ARJ etc).
  SET ECHOACTIVE <YES|NO>    Activate/suspend packing to your node.
  SET FILEACTIVE <YES|NO>    As above.
  SET SERVPSWD <pswd>        Change your ViaSERV password.
  SET SESSPSWD <pswd>        Change your SESSION password.
  SET INPKTPSWD <pswd>       Change your IN packet password.
  SET INPKTPSWD              Delete IN packet passwords.
  SET OUTPKTPSWD <pswd>      Change your OUT packet password.
  SET OUTPKTPSWD             Delete your OUT packet password.
  SET PKTFORMAT <format>     Change format: TYPE2 TYPE22 TYPE2+
  SET UNCOMPSIZE <bytes>     Max Uncomp size per archive 1000000=1mb.
  SET SYSOPNAME <name>       How ViaMAIL! should address you.
  SET BBSNAME <name>         Change your BBS Name.
  SET MAILADDR1 <part 1>     Your address 1 of 2.
  SET MAILADDR2 <part 2>     Your address 2 of 2.
  SET CITY <name>            Your city.
  SET STATE <state>          Not used in UK
  SET ZIPCODE <zipcode>      Your post code.
  SET VOICEPHONE <number>    Change VOICE number.
  SET DATAPHONE <number>     Change MODEM number.
  GET HELP                   This file.
  GET LIST                   List all Echoes or Filebone available.
  GET QUERY                  List only areas you have selected.
  GET UNLINKED               List only areas you do not have selected.
  GET STATUS                 List your ViaSERV! configuration set-up.
  GET RESCAN <conf> <num>    Rescan an echo. e.g. GET RESCAN SALES 100
  GET CONTACT                Information about your uplinks system.

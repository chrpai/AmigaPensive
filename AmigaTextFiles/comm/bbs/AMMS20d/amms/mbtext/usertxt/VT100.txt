
        Summary of DEC-VT100 escape sequences (inc. VT102-Color)
       ----------------------------------------------------------


CHARACTER SETS :
----------------
ESC ( A         UK CHARACTER
ESC ( B         US-ASCII CHARACTER
ESC ( 0         SPECIAL GRAPHICS CHARACTERS AND LINE DRAWING SET
ESC ( 1         ALTERNATE CHARACTER ROM
ESC ( 2         ALTERNATE CHARACTER ROM, SPECIAL GRAPHICS CHARACTER


TABS :
------
ESC H           SET TAB AT CURRENT COLUMN
ESC [ 0 g       CLEAR TAB AT CURRENT COLUMN (ESC [ g)
ESC [ 3 g       CLEAR ALL TABS


PROGRAMMABLE LEDs :
-------------------
ESC [ Ps;Ps;...;Ps q

Ps = 0 or None  ALL LEDs OFF
     1          L1 ON
     2          L2 ON
     3          L3 ON
     4          L4 ON


CURSOR :
--------
ESC [ A         CURSOR UP
ESC [ B         CURSOR DOWN
ESC [ C         CURSOR RIGHT
ESC [ D         CURSOR LEFT
ESC [ Pn A      Pn CURSOR UP
ESC [ Pn B      Pn CURSOR DOWN
ESC [ Pn C      Pn CURSOR RIGHT
ESC [ Pn D      Pn CURSOR LEFT

ESC [ H         CURSOR HOME (DIRECT CURSOR ADRESSING)
ESC [ Pl H      SET CURSORLINE/COLUMN=1 (DIRECT CURSOR ADRSSING) (Pl=1-24)
ESC [ Pl; Pc H  SET DIRECT CURSOR ADRESSING (Pl=1-24, Pc=1-80/132)
                (ESC [ Pl; Pc f)

ESC D           INDEX (MOVE CURSOR DOWN / BOTTOM -> SCROLL UP)
ESC M           REVERSE INDEX (MOVE CURSOR UP / TOP -> SCROLL DOWN)
ESC E           NEXT LINE (MOVE CURSOR TO THE BEGINNING ON THE NEXT LINE /
                BOTTOM -> SCROLL UP)

ESC 7           SAVE CURSOR, ATTRIBUTES AND COLORS
ESC 8           RESTORE CURSOR, ATTRIBUTES AND COLORS
                SAVE :  CURSOR POSITION
                        GRAPHICS RENDITION
                        CHARACTER SET SHIFT STATE
                        STATE OF WRAP FLAG
                        STATE OF ORIGIN MODE
                        STATE OD SELECTIVE ERASE
                        COLORS (VT102)

CHARACTER ATTRIBUTES :
----------------------
ESC [ Ps;Ps;...;Ps m

Ps = 0 or None  All Attributes OFF, SETTING DEFAULT COLOR
     1          BOLD ON
     4          UNDERLINE ON
     5          BLINK ON
     7          REVERSE VIDEO ON

     3Pc        TYPE COLOR (Pc = 0-7) (VT102)
     4Pc        BACKGROUND COLOR (Pc = 0-7) (VT102)

Pc = 0          BLACK (DEFAULT BACKGROUND COLOR)
     1          RED
     2          GREEN
     3          YELLOW
     4          BLUE
     5          LILAC
     6          TURQUOISE
     7          WHITE (DEFAULT TYPE COLOR)

ESC # 3         CHANGE THIS LINE TO DOUBLE HEIGHT TOP HALF
ESC # 4         CHANGE THIS LINE TO DOUBLE HEIGHT BOTTOM HALF
ESC # 5         CHANGE THIS LINE TO SINGLE WIDTH, SINGLE HEIGHT
ESC # 6         CHANGE THIS LINE TO DOUBLE WIDTH, SINGLE HEIGHT


SCROLLING REGION :
------------------
ESC [ Pt; Pb r  Scrolling Region (Pt: Top[1-66], Pb:Bottom[1-66], Pt < Pb)


ERASING :
---------
ESC [ 0 K       ERASE FROM CURSOR TO END OF LINE (ESC [ K)
ESC [ 1 K       ERASE FROM BEGINNING OF LINE TO CURSOR
ESC [ 2 K       ERASE ENTRIE LINE
ESC [ 0 J       ERASE FROM CURSOR TO END OF SCREEN (ESC [ J)
ESC [ 1 J       ERASE FROM BEGINNING OF SCREEN TO CURSOR
ESC [ 2 J       ERASE ENTRIE SCREEN


EDITING :
---------
ESC [ Pn L      INSERTS Pn LINES AT THE CURSOR
ESC [ Pn M      DELETES Pn LINES STARTING AT THE LINE WITH THE CURSOR
ESC [ Pn P      DELETES Pn CHARACTERS STARTING WITH THE CHARACTER AT THE
                CURSOR POSITION


PRINTING :
----------
ESC [ ? 1 i     PRINTS THE DISPLAY LINE CONTAINING THE CURSOR
ESC [ 0 i       PRINTS THE SCREEN DISPLAY (FULL SCREEN OR SCROLLING REGION,
                DEPENDING ON THE PRINT EXTENT MODE) (ESC [ i)


RESET :
-------
ESC c           TERMINALRESET


TEST :
------
ESC # 8         FILL SCREEN WITH "Es" (EEEEEE...)

ESC [ 2; Ps y   INVOKE TESTS

Ps = 1          POWER-UP SELF TEST (ROM CHECKSUM, RAM, NVR, KEYBOARD
                AND AVO IF INSTALLED)
     2          DATA LOOPBACK
     4          EIA MODERN CONTROL TEST
     8          REPEAT SELECT TEST(S) INDEFINITELY (UNTIL FAILURE OR POWER OFF)


CURSOR POSITION REPORT :
------------------------
ESC [ 6 n       INVOKED
ESC [ Pl;Pc R   RESPONSE


STATUS REPORT :
---------------
ESC [ 5 n       INVOKED
ESC [ Ps n      RESPONSE
Ps = 0          TERMINAL OK
     3          TERMINAL NOT OK


WHAT ARE YOU :
--------------
ESC [ c         INVOKED  (ESC [ 0 c)
ESC [ ? 1; Ps c RESPONSE
Ps = 0          BASE VT100, NO OPTIONS
     1          PROCESSOR OPTION (STP)
     2          ADVANCED VIDEO OPTIONS (AVO)
     3          AVO and STP
     4          GRAPHICS PROCESSOR OPTION (GPO)
     5          GPO and STP
     6          GPO and AVO
     7          GPO,STP and AVO


VT52 COMPATIBLE MODE :
----------------------
ESC A           CURSOR UP
ESC B           CURSOR DOWN
ESC C           CURSOR RIGHT
ESC D           CURSOR LEFT
ESC F           SELECT SPECIAL GRAPHICS CHARACTER SET
ESC G           SELECT ASCII CHARACTER SET
ESC H           CURSOR HOME
ESC I           REVERSE LINE FEED
ESC J           ERASE TO END OF SCREEN
ESC K           ERASE TO END OF LINE
ESC Pl Pc       DIRECT CURSOR ADDRESS (LINE AND COLUMN NUMBERS FOR DIRECT
                CURSOR ADDRESS ARE SINGLE CHARACTER CODES WHOSE VALUES ARE
                THE DESIRED NUMBER PLUS 31)
ESC Z           IDENTIFY (RESPONSE : ESC / Z)
ESC =           ENTER ALTERNATIVE KEYPAD MODE
ESC >           EXIT ALTERNATIE KEYPAD MODE
ESC <           ENTER ANSI MODE

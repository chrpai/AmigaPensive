                            Function 3 : Delete

Here you can delete your VK. The VK is then deleted and nobody can read it.
In the VK-List your name will disappear.
This function runs only if you have a VK, or the function is not
responding.
The function asks, if you really want to delete your VK. When you press
Return the function do nothing. You must Type "Y".

When you want a new VK use Edit (Function 1, Page 4) to do this.

Call:
Menu : with "D" or the Cusorkeys.
CLI  : VAK/Delete.

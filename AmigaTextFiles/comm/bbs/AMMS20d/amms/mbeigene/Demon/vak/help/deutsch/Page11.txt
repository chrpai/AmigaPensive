               Funktionen die vom CLI aus erreichbar sind :

VK aendern      : VAK/Edit
VK ansehen      : VAK/Show
VK loeschen     : VAK/Delete
Liste/Ansehen   : VAK/List
User VK ansehen : VAK <Username>
Hilfe-Modus     : VAK/Help


Die andern Funktionen kann man vom CLI aus nicht erreichen.
Um sie zu benutzen starte den VAK ohne Optionen oder Parameter.

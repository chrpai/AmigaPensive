                          Function 6 : List/View

This function is both, List and View.
When you call this function a list with all User they have a VK is shown.
Perhaps, the first Page. You can now select a user of whom you want to 
see the VK. In the Mode-Line (second line "Mode : ") you can see on which
page of the list you are now.

Help:

Cursor    UP : One user up.
Cursor  DOWN : One user down.
Cursor  LEFT : One user left.
Cursor RIGHT : One user right.

        T : To the top of the page.
        B : To the end of the page.

        N : Next page.                       F : To the first page.
        L : Previous page                    E : To the last page.

       CR : Show VK of selected user.  

  Q or X : End the List/View

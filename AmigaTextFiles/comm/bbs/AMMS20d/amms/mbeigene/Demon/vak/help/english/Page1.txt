                         Help for the helpmode ;)

In the helpmode for every function a page is implemented. This page
for the helpmode-help is Nr. 1. Nr. 2 is the index of the helpmode.

Helpmode:
Use the Cusorkeys to read every Page.

Cusor    UP : First Page (this one)
Cusor  DOWN : Last Page 
Cusor  LEFT : Previous Page
Cusor RIGHT : Next Page

          I : Shows the Index-Page.
          G : Ask for a number. Type the number of the page you 
              want to read.

          Q : Quit the Helpmode on every page.

                       Funktion 6, Liste/Ansehen : 

Diese Funktion ist beides : VK-List und VK ansehen.
Wenn Du Diese Funktion aufrufst wird eine Liste der User angezeigt die
eine VK haben. Allerdings nur die erste Seite. Du kannst nun mit den Cursor-
tasten einen Usernamen auswaehlen und mit RETURN die VK lesen.
In der zweiten Zeile ("Mode : ") wird angezeigt auf welcher Seite Du Dich
gerade befindest.

Hilfe:

Cursor   HOCH : Einen User nach oben.
Cursor RUNTER : Einen User runter.
Cursor  LINKS : Einen User links.
Cursor RECHTS : Einen User rechts.

         T : An den Anfang der Seite.
         B : An das Ende der Seite.

         N : Naechste Seite.                    F : Zur ersten Seite.
         L : Vorherige Seite.                   E : Zur letzen Seite.

        CR : VK des Users ansehen.  

  Q oder X : Beenden den Liste/Ansehen-Modus.

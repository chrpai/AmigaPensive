KONZEPT VOM AMMS :
------------------

AMMS ist so konzipiert, dass es beliebig erweiterbar ist :
- Eintragen neuer Befehle moeglich
- Alle Texte aenderbar, mehrsprachig
- Ueber 500 Funktionen der AMMS-Libraries von Programmierern nutzbar
  (Assembler-Includes komplett, C-Includes teilweise)
- Batch-Interpreter erlaubt das Erstellen eigener Menues (das mitgelieferte
  Menue ist nichts anderes als eine AMMS-Batch), neuer Befehle und
  Batchfiles, die auch User selber erstellen und nutzen koennen
- Temporaere Zugriffsvergabe auf hoeher priviligierte Befehle bei
  Batch-Befehlen moeglich
- 100%iger Amiga-Dos-Handler erlaubt das vollstaendige Nutzen aller
  Funktionen des Amiga-DOS
- Alle Systembatches aenderbar
- und vieles mehr ...







InterPort-Kommunikation :
-------------------------

- XCHAT : Komfortabler Zeilenchat
- FCHAT : Full-Screen-Chat
- PMSGS : Private Onlinemessages, die eingeloggten Usern sofort angezeigt
	  werden, Antwort moeglich, wenn User nicht eingeloggt, wird sie
	  bis zum naechsten Login gespeichert
- MESSAGE : Sofort eine Infozeile einem User/Port schicken




Full-Screen-Editore :
---------------------

- PRO-EDITOR : AMMS-Full-Screen-Editor
- MEGAED : Optionaler Full-Screen-Editor (inc. Directory-Requester usw.)
	   Erhaeltlich von CPU@PHASE1 (Fastnet)

Daten zu Message/PM/File-Systemen :
-----------------------------------

- 1600 Nachrichten-Bretter mit je max. 800 Nachrichten
- 640 File-Bretter mit je max. 1400 Files
- 255 Directories zur Unterteilung
- Max. 800 private Nachrichten pro User
- In jedem File-Brett private Files moeglich, ein vom System unterstuetztes
  Privatfile-Brett (:SYSTEM/PRIVAT).
- Sehr maechtiger Befehl READ
- Sehr maechtiger und komfortabler Befehl FILES
- Sehr maechtiger und komfortabler Befehl DISK TOOL, der fuer direkte
  DISK-Arbeiten gedacht ist, kann auch fuer das komfortable Einbinden
  von CDs benutzt werden (FASTDIR-Unterstuetzung)
- Frei programmierbare Amiga-Dos-Batches im File-System (extrem maechtige
  Schnittstelle im File-System), 100%iger Amiga-Dos-Handler

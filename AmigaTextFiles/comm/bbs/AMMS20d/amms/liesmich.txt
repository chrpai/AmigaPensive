        - Installation :
          Alle Dateien aus diesem Archiv sollten in ein Verzeichnis auf einer
          Festplatte kopiert werden.
          Das Programm kann nun vom CLI aus mit

          CD <MAILBOXVERZEICHNIS>
          EXECUTE MBSTART.BAT

          gestartet werden. (Bei Verwendung der Shell kann das EXECUTE auch
          weggelassen werden). Soll das Programm von der Workbench aus
          gestartet werden, muss dieses mit IconX geschehen.


        - SETUP
          Mit dem Programm SETUP lasst sich der Boxname sowie die maximale
          Useranzahl und die maximale Anzahl der Protokolleintraege
          einstellen. Man sollte beachten, dass sich diese Werte direkt
          darauf auswirken, wieviel Speicher die Mailbox benoetigt.
          Pro moeglichen User werden 40 Bytes Speicher benoetigt, pro
          Protokolleintrag 60 Bytes.
          Soll die Box im FastNet eingegliedert werden, sollte der Boxname
          moeglichst Kurz gehalten werden (12 Zeichen). Im Boxnamen sollte
          kein Space vorkommen.


        - Konfiguration der Ports
          Neue Ports koennen von der Box aus mit dem Befehl ADD PORT angelegt
          werden, standardmaessig sind die Ports CON0 (Console) und SER0
          (Modem an interner serieller Schnittstelle) voreingestellt.

          Fuer die Konfiguration der Port-Einstellungen existiert der Befehl
          EDIT PORT. Hier koennen die Connect-Strings etc. an ihr Modem
          angepasst werden.

          Mit Edit Port koennen folgende Daten eingestellt werden:

          DEVICE: Device fuer den Port. Jede zur serial.device kompatible
                  Device kann genutzt werden. Zusaetzlich stehen die
                  speziellen Devices CON (fuer die Consolen) und BAT (fuer
                  Hintergrund-Batchports) zur Verfuegung.

          UNIT:   Deviceunit fuer den Port. Die interne serielle Schnitt-
                  stelle hat die Unit 0.

          DEVICE OPTS: Device abhaengige Optionen. Siehe Datei PORT.DOK.

          DEFAULT BAUD: Baudrate, mit der das Modem nach einem Anruf bzw.
                        nach dem Portstart angesprochen wird.

          RESET-STRING: Wird nach dem Start des Ports EINMAL gesendet.

          INIT-STRING: Wird nach jedem Anruf und beim Start des Ports
                       gesendet.

          DIAL-PREFIX: Befehlssequenz VOR der Telefonnummer zum Waehlen.

          DIAL-SUFFIX: Befehlssequenz HINTER der Telefonnummer zum Waehlen.

          ANSWER-STRING: Befehlssequenz um einen ankommenden Anruf
                         entgegenzunehmen.

          HANGUP-STRING: Befehlssequenz zum Beenden der Verbindung. Kein
                         String = Beenden der Verbindung ueber DTR-Signal.

          RING-MESSAGE: Meldung des Modems beim erkennen des Klingelsignals.

          RINGS: Anzahl der Klingelsignale vor dem Senden des Answer-Strings.
 
          CONNECT WAIT: Anzahl der Sekunden die nach dem eintreffen eines
                        Zeichens auf eine Connect-Meldung gewartet wird.

          QUIET: Port "Quiet" starten (siehe PORT.DOK).

          AUTOKILL: Port nach Anruf beenden (siehe PORT.DOK).

          TASKPRI: Taskprioritaet fuer diesen Port.

          In der unteren Tabelle koennen mit Return & den Cursortasten
          die Connectstrings (Wildcards werden unterstuetzt) und die
          zugehoerigen Baudraten fuers Protokoll Bd(P) und zum Modem
          Bd(M) eingetragen werden. Zusaetzlich kann angegeben werden,
          welche Batchdatei nach dem Connect unter welchem User
          gestartet werden soll. Die Standardeinstellung dafuer ist
          User=Login, Batchdatei=mbbatch:login.

          Es reicht, wenn bei allen Meldungen vom Modem jeweils nur der
          signifikante Teil eingegeben wird. Statt eines "CONNECT 2400^M^J"
          reicht ein "2400^M^J" voellig aus.

          In allen Strings bedeutet ein "^", dass der nachfolgende Buchstabe
          in den entsprechenden CTRL-Code umgewandelt wird (z.B. "^M" =
          CTRL-M = RETURN). Wird im String ein "^" Zeichen benoetigt, so
          muss es als "^^" geschrieben werden.
          Bei den Befehls-Strings (Reset,Init,Answer,Hangup) bewirkt eine
          Tilde ("~") eine Verzoegerung um ca. 1/2 Sekunde bevor das naechste
          Zeichen ausgegeben wird.

          Wurde das Modem so konfiguriert, dass es die Anrufe selbststaendig
          beantwortet (S0 ungleich 0) so sollte das Feld Ring freigelassen
          werden. Diese Methode kann ich jedoch nicht empfehlen, da sie
          einige Nachteile hat, z.B. nimmt das Modem auch ab, wenn die Box
          abgestuerzt sein sollte.

          Fuer gaengige Modems existieren im Verzeichnis MBDEVS: bereits
          einige Voreinstellungen. Diese koennen vom CLI aus mit
          COPY MBDEVS:<VOREINSTELLUNG> MBDEVS:<PORT>.SET in die Settings-
          datei fuer den entsprechenden Port kopiert werden. Also um
          z.B. den Port SER0 fuer ein USR Dual Standard (14.4k Version)
          zu konfigurieren, muesste man nur
          COPY MBDEVS:DUAL14.4.SET MBDEVS:SER0.SET
          ausfuehren.

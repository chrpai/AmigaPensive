
SysOp / CoSysop Menus for Zeus Pro BBS
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

These are improved scripts that I've been using for a while on  my  BBS  and
have  tuned to almost exactly what I want. That said, before installing them
you should back up your Text: and Scripts: drawers :)


     Text (dir)
          SysOp (dir)
            EditUser.TXT                     FileEdit.TXT
            SysOpMenu.TXT                    Template.TXT

These are screens / displays needed by the scripts below.


     Scripts (dir)
          Files (dir)
            ChangeFileArea.zeus              EditFile.zeus
            SigChange.zeus

Only EditFile should be copied straight from  here.  My  ChangeFileArea.zeus
behaves internally a little differently from the ones supplied with Zeus. If
you have a working ChangeFileArea.zeus, don't  copy  mine  across  with  out
checking it out thouroghly and backing up the old one. (SigChange is part of
ChangeFileArea)


          SysOp (dir)
            EditUser.zeus                    FileEdit.zeus

EditUser.zeus was written by Anthony Brice. I updated it so it took  account
of  the  'UserList'  door being converted to a ZDoor from a CLIDoor, but not
much else.

FileEdit.zeus is a general file maintaince tool - Delete files, Move  files,
Upload new files direct to an area (in case you have uploaded files diverted
to a special upload area), Scan for Unvalidated files, and a direct link  to
Files/EditFile  for  more  detailed  single  file  editing. I think this was
written origionally by Rod Whitney of Ami-TECH BBS, but I could be wrong...


            FileMaintenance.zeus             SysOpMenu.zeus

FileMaintenance - written by Rod Schnell. I haven't done anything  to  this,
but it's a nice bulk file checker and does some other nice things.


            ZLogs.zeus

Original Excelsior! program (Logs.rexx) by Glenn J. Schworak
Converted to Zeus by ?

This is a little impractical if you have a 512kb log file to go through,  as
this  lists from Start to Finish. A more practical approach would be to list
the file backwards, to show the  most  recent  first.  (With  possibly  some
intelligent  showing  of  some  blocks of text forwards (e.g. a Zmailer call
session). I may do this eventually, I have code  from  DayDream  doors  that
already does it for file lists)

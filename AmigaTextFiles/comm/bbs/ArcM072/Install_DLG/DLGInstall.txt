 Greetings, fellow DLG-sysop!

 Here are the instructions for installing ArcMaster in DLG systems.

Because  ArcMaster does not require any specific BBS-program it can be
installed  in  many  systems.   Because  of this, it does not have any
uploading routines.  For DLG usage you will need some external program
which  can upload private files to specified user.  MagicUpload is one
(made by me :) which can do the job and it's included.

 This directory holds an example config-file for ArcMaster, configured
for  using  MagicUpload.   Modify it to suit your needs and copy it to
the S:-directory.

 I also included a batch file which is required for starting ArcMaster
from  DLG.   Copy  it to the DLGCONFIG:Batch/-directory and then, make
this menu entry into your FILE-main menu.

[ 1] Letter:                   #
[ 2] Menu script: (path/name)  dlgconfig:batch/arcmaster.batch
[ 3] Edit file:
[ 4] Description:              ArcMaster
[ 5] Type:                     Menu script
[ 6] Help File:                FILE_MAIN/#
[ 7] Lower level:              5
[ 8] Upper level:              255
[ 9] Hidden:                   NO
[10] Load type:                OVERLAY
[11] Ask user if sure:         NO
[12] Pend messages:            YES
[13] Cli mode:                 YES
[14] Pause on completion:      NO
[15] Log value:                None
[16] Activity string:          Using ArcMaster
[17] Priority:                 DEFAULT
[18] Edit help file


 Standard Custom Fields
 ----------------------
 Do NOT put as many fields as you can find on the FilePather line.
 The main idea of FilePather is to keep the filesize down by removing ads.
 Also, the current line limitation in FPBase is 1000 bytes.

 All strings that contains spaces must be enclosed with doublequotes (").
 n=Number
 s=String

 Name:			Template:		Example:
 ----------------------------------------------------------------------------
 CoSysOp=		CSO_1 | CSO_2 | CSO_N	"Rainman/Dual Hex | John Smith | Tarzan"
 Modem=			MOD_1 | MOD_2 | MOD_N	"28.8DS | 16.8DS"	(see note 1)
 Size_of_HD=		n(Mb|Gb)		30Gb
 Amount_of_RAM=		n(Mb|Gb)		56Mb
 Processor=		PROCESSOR		68060
 Clock_frequency=	n(Mhz)			66Mhz
 Geographic_location=	TOWN,(STATE/COUNTRY)	"Säffle,Sweden" or "Miami,Florida"
 Legend=		LEGEND			"As faster as better!"
 ComputerType=		COMPUTERTYPE		Amiga
 OS=			OPERATIVE SYSTEM	"KickStart 4.0"
 FidoNet=		n_1 | n_2 | n_N		"2:203/804.13 | 2:203/807.0"
 AmigaNet=		n_1 | n_2 | n_N		39:157/101.15
 Email=			s_1 | s_2 | s_N		"chris@netcom.com"
 Nr_of_nodes=		n			4	(For boards with ringdown)
 Node=			n			2	(The node the file was uploaded on)
 Message=		MESSAGE			"Contact me for module swapping"
 Program_version=	n			2.0	(see note 2)
 Program_description=	DESCRIPTION		"FILE_ID editor"	(see note 2)
 Program_host=		HOST			"${FilePather/Name}"	(see note 2)
 Uploaded_by=		NAME			"Bill Clinton"	(set by BBS)
 VoiceNumber=		n			+46-033-33000
 Sysop=			SYSOP			Clark Olofsson	(see note 3)
 Open=			TIME			22-08		(see note 4)
 TimeZone=		OFFSET			+1		(see note 4)
 ----------------------------------------------------------------------------

 Note 1:
    This field describes what kind of modems that are connected on the
    different nodes. ie 28.8DS, V.34, 16.8DS, V32bis, VFC, HST, Zyxel,
    ISDN etc. This is valuable information for an user, who ofcourse want
    the highest possible connect rate. Ofcourse are the descriptions in the
    same order as the phone numbers.

 Note 2:
    These are for Type='Program' ie. a fileprocessor like DIZ-ED, an
    AdStripper or likewise. Program_Host contains the name of the
    system/person that used the program. This is normally the line above,
    but should be stated here too to avoid mistakes.

 Note 3:
    Although there is dedicated space in the FilePather line, the sysops
    name AND location will not fit if these are to long. The Sysop field is
    mostly for 'elite' users, who is able to squeeze in both their handle
    and groupname in FilePather line.

 Note 4:
    If you doesn't have open 24 hours a day, this field can be used to
    specify your open times. Do only use whole hours, specifing minutes
    is silly. Also, "TimeZone" must be used to specify your timezones
    offset from the GMT (Greenwich Mean Time) zone.

Grotte 2.0, version demo

C'est un jeu d'action qui peut tourner sur n'importe quel terminal
ANSI, y compris sur un BBS ou directement sur un écran Amiga.

C'est une version demo, avec 3 niveaux au lieu de 100.

Caractéristiques principales:
 - Compatible avec le système
 - Marche sur n'importe quel Amiga
 - Grande animation
 - Ecrit 100% en Modula-2
 - English doc.


INSTALLATION DU PROGRAMME (A partir du workbench):

 Glisser l'icône du tirroir 'Grotte' à l'endroit où le programme
doit être installé (le programme et tous les fichiers nécessaires
sont dedans).

C'est tout !-)


UTILISATION:

 Il y a deux programmes principaux, 'GrotteDemo' et 'GrotteBDemo'.
Ces deux programmes sont les mêmes, mis à part qu'en cas d'erreur,
GrotteBDemo quitte directement sans requester, alors que GrotteDemo
affiche des erreurs claires.
 Utilisez 'GrotteBDemo' pour installer le jeu sur un BBS (pour éviter le
moindre requester de bloquer tout le BBS).
 Utilisez 'GrotteDemo' pour jouer directement sur l'Amiga.
 
 Pour détérminer quelle type de terminal le programme doit utiliser,
reglez le tooltype 'TERMINAL_LIB' à l'aide du menu 'Informations' du
Workbench. Il y a deux types disponibles, qui se présentent sous la
forme de librairies:
- Libs/topazterm.library:
 Cette librairie simule un terminal couleur ou noir et blanc sur un
écran intuition, en topaz 8. Utilisez-la pour jouer directement sur
l'Amiga.
- Libs/stdio.library:
 Cette librairie utilise la redirection par défaut (qui peut être modifiée
dans une commande Cli par '<>') et permet de jouer sur n'importe
quel terminal distant compatible ANSI, y compris sur une fenêtre
AmigaDos, en utilisant '<> RAW:'. Attention, le gestionnaire 'CON:'
ne marche pas car il ne renvoie les touches qu'après un <RETURN>.
 Avec cette librairie, le programme ne peut plus être lancé depuis
le Workbench car celui-ci ne redirige pas le programme.
 En cas de déconnection (EOF), le programme quitte directement.

  Le tooltype 'SOUND_LIB' doit pour l'instant toujours être réglé
sur 'Libs/grottenosound.library'. Il doit être spécifié !

  Avec le Kickstart 1.3 ou moins, le chemin d'accès complet doit être
spécifié pour les deux librairies.

  Le tooltype 'TASKPRIORITY', s'il est spécifié, détermine la
priorité d'éxécution du programme.

 Si le programme GrotteBDemo ne démarre pas pour une raison inconnue
lors de l'installation sur un BBS, le programme GrotteDemo peut être
utilisé temporairement afin de connaître la cause; mais n'oubliez pas
de règler correctement le tooltype 'TERMINAL_LIB' !!


NOTE:

 Le programme ne fonctionne que sous Kickstart 1.1 ou plus  ;-)))

 Vous trouverez dans le tirroir 'Grotte/Docs' d'autres informations sur
le jeu lui-même. Attentions: ces fichiers sont prévus pour être lus
depuis le programme Grotte, d'où leur structure particulière; il peuvent
toutefois être lus par AmigaGuide, MultiView ou n'importe quel éditeur.

 Cette version demo a toutes les caractéristiques de la version complète
mais il n'y a que 3 niveaux.

 Le fichier 'Grotte/Decors' ainsi que les fichiers du tirroir
'Grotte/Docs' peuvent être compactés par une méthode xpk: il seront
toujours reconnu par le programme.

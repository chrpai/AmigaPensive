
FileCheck - oldest history - version 0.xx up to 2.51
----------------------------------------------------

V0.xx - a long time ago ;)

 - the first versions which cames from Ork


V1.0b - 13.06.1996

 - i hope it works fine :)


V1.00 - 22.06.1996

 - in the file_id the protection-flags will be set to "rwed"
   because you could not change the e-comment


V1.10 - 05.07.1996

 - files can be add also to ZIP-archives
 - file_id's can be extract from a JPEG-picture
 - small bug removed


V1.20 - 11.07.1996

 - new striplist (one for all (LhA, LZX, ZIP))
 - now with duplicate-checker
 - on a moved file, the reason will be written in the AMMS-@hlp-file
 - the file_id will be overworked after the extraction


V1.30 - 17.07.1996

 - many parts has changed (there are new bugs?!;)
 - libraries will be load systemfriendly now
 - filenames can now stand between quotation marks
   (parsing of the (rexx)dos(support).library)
 - bug on LhA removed, if the file was corrupt
 - Textract and GifDesc not longer needed, because i have my own routine
   for GIF, JPEG an Text
 - JPEG works fine at first


V1.40 - 28.07.1996

 - ASCII-Code '13' will be removed after extraction of the file_id.diz
 - some routines changed and swapped
 - faster and better strip-routine for LZX and ZIP
 - portnames can now contain spaces
 - RAR2.0-archives can now be handled, because there is a new UNRAR


V1.50 - 02.08.1996

 - some bugs in the new strip-routines removed
 - FileCheck is now REGGI-WARE ;)
 - new routine to optimize the file_id
 - file_id-extractor for Text, GIF and JPEG improved


V1.60 - 08.08.1996

 - in file_id's empty lines with ASCII '13' will be removed
 - file_id-extractor for Text, GIF and JPEG new and faster
 - gif- an jpeg-routine combined
 - new config-file 'FileCheck.nostrip' prevent the adding of adverts
   on the given fileboards


V2.00 - 08.09.1996

 - source completly overworked
 - temporary directory can be given in the config-file
 - new filetypes added
 - adaption to AMMS 3 (filenamelength upto 26 chars)
 - bug in the duplicate-checker found and removed
 - chars can be converted and stripped out of the file_id
 - new option 'nocvt' do not convert the file_id
 - new textadder without JOIN (files can be added to the top and to
   the buttom of an text-file)
 - buffersize for internal operations can be given
 - new option 'nocrcheck'
   (this option disabled the distinction of AMIGA- and IBM-file_id's)


V2.10 - 19.10.1996

 - ARJ-Archives are known, but the archives will be checked only
 - duplicate-checker can be disabled for special-users
 - bug removed by the extraction of file_ids in executable files
 - turboscan-mode for the duplicate-checker
 - new command called 'ScanDir'
   (to scan (sub)dirs for the duplicate-checker)
 - chars can be convert on AMIGA- and IBM-file_id's different


V2.20 - 20.10.1996

 - turboscan-mode is now really turbo


V2.30 - 30.12.1996

 - lines can be stripped out of file_id's
 - add a line to file_id's is now possible
 - uploader-name will be saved if the file is corrupt or it is a duplicate
 - small changes on the file_id-routines
 - dokumentation enhanced


V2.40 - 01.02.1997

 - FileCheck works with keyfile now (for registered users)
 - SETRETURN is directly supported
 - temporary directory will be removed
 - ZIP is a little bit faster
 - now with AmigaGuide-documentation
 - text-documentation removed


V2.50 - 23.03.1997

 - bug on executable-files removed
 - bug on the duplicate-checker removed
 - spaces at the end of a line in file_id's will be removed
 - on ZIP-archives files with more than 8.3 chars can be add
 - error-text will be printed if there is an error with the keyfile
 - routines for selfextracting archives removed
 - output-texts now configurable
 - lines will be add on file_ids if no file_id exists
 - some other optimizes


V2.51 - 17.04.1997

 - bug in the file_id-routines removed
   (if no file_id was found, sometimes a @hlp-file was created)

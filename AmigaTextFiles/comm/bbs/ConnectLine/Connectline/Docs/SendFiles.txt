hier eine kurze Funktionsübersicht zu SendFiles (Guide ist in
Arbeit):  SendFiles ist grob in die Abschnitte "Dateien" und
"Absender & Empfänger" unterteilt.


Dateien-Sektion
---------------

Es können Dateien auf einer Ebene oder rekursiv ganze
Verzeichnishierarchien eingelesen werden, entweder über die
Buttons oder einfach indem man Datei- und Directory-Icons auf die
Liste fallen läßt (alles natürlich multiselectfähig).

Jede eingelesene Datei wird mit den im Optionsfenster
eingestellten Vorgabedaten ausgestattet (in einer späteren
Version wird SendFiles versuchen, bestimmte Parameter optional
automatisch zu bestimmen).

Für die vier Dateiparameter "Betreff", "Export-Dateiname",
"Kommentar" und "erweiterter Kommentar" unterstützt SendFiles
die Tokens
 %d = Dateibasisname, ohne Pfad und ohne Extension
 %e = Extension inkl. '.'
 %k = Kommentar (FileComment)
 %p = Pfad mit Abschlußzeichen
Die Verwendung dieser Tokens wird aus der Vorgabe deutlich.
In "Kommentar" wird zusätzlich der folg. Token unterstützt:
 %s = Short-Comment aus Datei in "erweiterter Kommentar"

Für rekursive Aufnahme eines Verzeichnisses kann eine Namensmaske
und der Ausschluß von Icons eingestellt werden.

Bei einem Doppelklick auf eine Datei in der Liste wird je nach
Dateityp eines der im Optionsfenster eingestellten Programme
aufgerufen (dort wird %s durch den Filenamen ersetzt).


Absender & Empfänger
--------------------

Als Absender werden nur User mit Priorität >= 90 zugelassen.

Die Empfängerliste darf beliebig mit Usern und Brettern gefüllt
werden, die beiden Kategorien werden beim Versenden getrennt.
Für User und Bretter stehen Auswahllisten (mit Filtermöglichkeit)
zur Verfügung (Auswahl per Doppelklick bzw. <Return>).


Allgemein
---------

"Senden" schickt (nach einer Sicherheitsabfrage) die ausgewählten
Files an die eingetragenen Empfänger.  Dateien, die nicht
verschickt werden können, bleiben in der Liste.

"Ende" (gleich Close/Escape) beendet SendFiles ohne
Sicherheitsabfrage.

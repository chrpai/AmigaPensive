
                         FAME DEVELOPER DISK V0.25
                         ~~~~~~~~~~~~~~~~~~~~~~~~~

 This disk contains the FAME Development files for FAME programming V0.25.

             The following archives are included on this disk:

FAME_DEV.LHA - Contains FAME.library Autodoc and two FAME door examples in C.

FAME_C.LHA   - Contains includes and examples for programming in SAS/C and
               StormC.

FAME_E.LHA   - Contains modules and examples for programming in AmigaE.

FAME_ASM.LHA - Contains includes and examples for programming in Assembler.

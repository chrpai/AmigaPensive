Einleitung

    Ahunt ist eine Portierung des Multiplayer Unix-Spiels hunt. Die Original-
    version von Hunt ist fuer eine Netzwerkumgebung konzipiert. Ahunt
    unterstuetzt kein Netzwerk, sondern ist z.B. fuer Mailboxen mit mehreren
    seriellen Ports gedacht.

    Soweit moeglich, wurden fast alle Texte lokalisiert. Die Sprache Englisch
    ist fest eingebaut, fuer Deutsch ist ein entsprechender Katalog vorhanden.


Installation

    Ahunt kann mit jedem Mailbox-Programm verwendet werden, dass einen
    Standard I/O-Handler zur verfuegung stellt. Der Handler muss den RAW-
    Modus unterstuetzen.

    Als Emulation wird ANSI/VT100 mit 8 Farben verwendet.

    Zur Installation sollte der Inhalt des Ahunt-Verzeichnis an einen
    geeigneten Ort kopiert werden. Assigns sind nicht notwendig.

    Ahunt besteht aus zwei ausfuehrbaren Programmen:

    ahuntd

        Dieses Serverprogramm muss einmal, z.B. beim Start der Mailbox,
        gestartet werden. ACHTUNG! Es benoetigt mindestens 20000 BYTES STACK!
        In einer Batch sollte also vorher der Stack erhoeht werden.

        Beispielaufruf:

            stack 20000
            run ahuntd

    ahunt

        Dieses Programm wird zum Spielen aufgerufen. Es erwartet als
        Parameter einen Portnamen und einen Spielernamen. Es kann auch zum
        ausprobieren direkt aus der Shell aufgerufen werden.

        Beispielaufruf:

            ahunt cli sysop

WEITERLEITEN
------------

Einbinden in CL mit :  CONNECTLINE:COMMANDS/WEITERLEITEN %p

Die langen Kommentare werden bei meinem WEITERLEITEN auch mit
uebernommen. Der Anwender wird gefragt ob der alte Uploader
beibehalten werden soll oder auf den eigenen Namen gesetzt werden
soll ( OAB wird dann gesetzt ). OEM wird ebenfals gesetzt sowie
der alte IDunter BEZ .
Anwahl des Zielbretts wie es sich in meinen Augen gehoehrt 
( per Cursor-Steuerung ). Nach dem Weiterleiten wird gefragt ob die
alte Mail geloescht werden soll.

IndexRecover
------------

Dieses Tool liegt im Tools-Verzeichnis dieses Archivs.
Dieses kleine Tool versucht bei verlorengegangenen Brettindex
und Message Dateien noch das beste drauss zu machen.
Hierbei sind allerdings keine Wunder moeglich aber jeder
der auf einmal vor einem Directory mit 250 Outbound Dateien
steht wird es zu schaetzen wissen =:-)) .

Es untersucht die OUTBOUND Dateien nach dem Archivtyp und
haeng die Extension an den Filenamen ( z.b. Outbound47.LHA ). 
Erkannt werden hier LHA, LZX, LZ, DMS und ZIP.
Anschliesend wird das Archiv nach einem moeglichen FILE_ID.DIZ
durchsucht, ist dieser vorhanden ( und nur dann ) wird das
Archiv zusammen mit dem FILE_ID.DIZ als langen Kommentar ins
angegebene Zielbrett einsortiert.
Es werden nur Archive der oben genannten Archivtypen einsortiert
und auch nur wenn ein File_id.diz vorhanden ist.

Auf die Art bekommt man wenigstens den Grossteil der Archive
wieder fuer die Box zurueck.


Aufruf :

Zuerst alle Outbounds aus dem Brettdir in ein Neutrales Directory
verschieben.
Dann das Programm aufrufen mit :

IndexRecover <DOSPfad wo die Outbounds liegen> <Zielbrettname>


Dieses Tool ist speziell einem Sysop aus Kiel gewipnet der seit
drei Wochen versucht verzweifelt mit CL online zu gehen es aber
bisher nich konnte weil er dieses Tool brauchte und drauf wartete
( er ist einer von dehnen der keine Outbounds im Opus mehr sehen
  kann ).

LESEN    DOWNLOAD
-----------------

Was ist neu :

jetzt koennen fuer einige user seperate downloadraten
fuer einzelne bretter bestimmt werden.....


Wie geht das :

im DOS-pfad des entsprechenden bretts liegt ein file
namens  USER.RATIO  hier kommen zeilenweise die user
mit ihrer rate rein wenn sie vom standart abweichen.

angaben sind in 1/1000 also z.b.  :

DUMMY 1500

hiermit gilt fuer user  DUMMY  eine rate von 1,5 im ent-
sprechenden brett. Oder :

DUMMY 500

hiermit hatt er eine rate von 0,5 im entsprechenden brett.
siehe hierzu auch die beispielconfig die diesem archiv
beiliegt.


Und was wenn :

mehrere raten in konflikt kommen.....
die rate wird in folgender reihenfolge ueberprueft :

freedownloadbrett ----------> wenn ja bleibts dabei
                   |
                   |--> wenn nicht existiert neue rate 
                        im configfile fuer dieses brett
                        fuer diesen User 
                           |
                           |
                           ------> wenn ja wird diese genommen
                           |
                           |
                           ------> wenn nein die aus den userconfigs
                           
                           
Wie erfaehrts der User :

durch eine warnung vorm download ( neue catalogfiles )


Was ist sonst neu :

bei downloads von gemerkten files von der console wird
der downloadpfad nur noch EINMAL abgefragt.

zur besseren kontrolle wird im verzeichnis CONNECTLINE:LOG
ein logfile namens  DOWNLOAD.LOG  mit allen downloads
mitgefuehrt.


SENDEN
------

dieser neue SENDEN befehl erlaubt wieder das versenden
von eilmails online als user.

In der Sysopinfo zeile der user die eilmails verschicken 
duerfen muss der parameter   |E|  eingetragen werden.

( bei Usern die ueberall LOESCHEN und eilmails verschicken
  duerfen steht den z.b. in der infozeile  |L|E|  ).


bei systeme an die eilmails abgesetzt werden duerfen muss
in den jeweiligen Prefs im systemeditor das eilmailgadget
aktiviert sein.

in das verzeichnis CONNECTLINE:c muss der befehl NCALL
der diesem archiv beiligt kopiert werden. dieses programm
ist fuer den eigentlichen netcall nach dem logoff des users
zustaendig.

im verzeichnis  CONNECTLINE:log/EILPMpuffer  wird zu jedem
user der eilmails verschickt ein getrenntes file abgelegt
wo die abrechnung der eilmails vorhanden ist. diese wird
den spaeter auch von meinem abrechnungstool mit ausewertet.


So :

jetzt solten alle klarheiten beseitigt sein.......

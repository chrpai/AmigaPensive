Zeus is loaded as a commodity and can be shut down in a number of
different ways.


1) Use the hotkey shortcut CTRL-ESC.
2) Load up SYS:Tools/Commodities/Exchange, select Zeus BBS from the listview and press the
3) Send a QuitZeus command to the ARexx port ZEUS. This can be acheived with the following script: 

      ---------------cut----------------
      /*
      ** Close Down Zeus
      */

      Options Results

      Address 'ZEUS'

      QuitZeus
      ---------------cut----------------


4) Double click on the "Zeus:Shortcuts/BBS/ShutdownZeus" icon.

NAME
       RemUserXData -- Remove xdata from user account.

   SYNOPSIS
       RemUserXData  <TAG> [KEY]

   FUNCTION
       Remove an item of data from a user's Extra Data.

   INPUTS
       TAG -- A case sensitive 4 character tag matching a tag
              stored in the user's extra data file.

       KEY -- A user pointer to a user structure from LoadUser. If
              the pointer is not supplied then the current user
              will be used.

   RESULT

   RC
        0 -- Extra data entry removed.
       10 -- Bad arguments.
       20 -- Bad user pointer / No user online.

   EXAMPLE

   NOTES
       Asynchronous

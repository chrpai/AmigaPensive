NAME
       GetFullPath

   SYNOPSIS
       GetFullPath '"<FILE>"'

   FUNCTION
       Find the physical path on disk of the given file (which
       is in the Zeus file catalogues).

   INPUTS
       FILE -- The name of the file to find the full path for.

   RESULT
       The full path and file name.

   RC
       0 -- Successful
       2 -- Unable to lock file
       5 -- File does not exist

   EXAMPLE

   NOTES
          Asynchronous

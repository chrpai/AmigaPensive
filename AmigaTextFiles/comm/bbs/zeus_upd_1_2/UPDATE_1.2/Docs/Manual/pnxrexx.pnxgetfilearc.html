NAME
      PnxGetFileArc

   SYNOPSIS
      PnxGetFileArc <fullpath>

   FUNCTION
      Needs full path to a file. This function will then try to determind
      what archiver the file is archived with using Zeus' archiver
      configuration.

   NOTES

   INPUTS
      FullPath  Path to a file to check.

   RESULT
      RC  0 Ok, the archiver number is returned in RESULT.
      RC  5 Bad arguments.
      RC 11 Couldn't open the file.
      RC 12 Unknown file type.

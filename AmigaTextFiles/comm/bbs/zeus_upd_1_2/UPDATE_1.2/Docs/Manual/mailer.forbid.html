NAME
       Forbid

   SYNOPSIS
       Forbid <NONE|XMAIL|FREQ|ALL>

   FUNCTION
       Temporarily change the Forbid settings so certain files
       cannot be sent to you.

   INPUTS
       NONE  -- Don't forbid receiving any files.
       XMAIL -- Don't allow compressed mail.
       FREQ  -- Don't allow file requests.
       ALL   -- Don't allow any files.

   RESULT

   RC

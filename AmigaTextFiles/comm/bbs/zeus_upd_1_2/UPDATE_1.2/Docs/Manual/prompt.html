NAME
       Prompt -- Prompts a user.

   SYNOPSIS
       Prompt -- '<TAG>'

   FUNCTION
       Prompt a user for input using a language tag.

   INPUTS
       TAG -- The language tag to create the prompt with.

   RESULT

   RC
        0 -- Successful
       10 -- Bad args

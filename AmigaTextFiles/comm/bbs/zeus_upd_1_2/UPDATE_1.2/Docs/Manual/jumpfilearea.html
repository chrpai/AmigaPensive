NAME
       JumpFileArea

   SYNOPSIS
       JumpFileArea <NEXT|PREV|FIRST|LAST> [IGNORESIG] [IGNOREACCESS]

   FUNCTION
       Changes the current file area to the one specified.

   INPUTS
       NEXT   -- Jump to next area
       PREV   -- Jump to previous area
       FIRST  -- Jump to first area
       LAST   -- Jump to last area

       IGNORESIG    -- Ignore the range limits of the current SIG.
       IGNOREACCESS -- Enter area even if the user does NOT have access to it.

   RESULT
       Area number changed to.

   RC
        0 -- Successful
        5 -- Could not change to specified area
       10 -- Bad arguments

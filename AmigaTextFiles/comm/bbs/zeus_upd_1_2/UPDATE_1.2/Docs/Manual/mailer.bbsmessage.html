NAME
       BBSMessage

   SYNOPSIS
       BBSMessage '"<TEXT>"'

   FUNCTION
       Another line of text giving instructions of how to login to the BBS,
       after the banner has been displayed and the BBS is available. The `<'
       character may be used to specify a text file.

   INPUTS
       TEXT -- Text to display

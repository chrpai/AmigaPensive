NAME
       FileNameToNumber

   SYNOPSIS
       FilenameToNumber '"<FILENAME>"'

   FUNCTION
       Returns the number belonging to the specified file if the
       file is in a File Base which supports file numbers.

   INPUTS
       FILENAME -- The name of the file in the Zeus catalogue

   RESULT
       File number.

   RC
        0 -- Successful
        5 -- No such file
       10 -- Bad arguments

   EXAMPLE

   NOTES
          Asynchronous

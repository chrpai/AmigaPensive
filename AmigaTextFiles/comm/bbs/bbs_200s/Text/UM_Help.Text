                                Online Help

                      +-----------------------------+
                      |          User Menu          |
                      |          ~~~~~~~~~          |
                      | CS = Chat SysOp             |
                      | FU = Find User              |
                      | LA = List all Users         |
                      | LI = Logoff Information     |
                      | MI = Message and Mail Info  |
                      | MM = Main Menu              |
                      | SI = Security Information   |
                      | TC = Top Caller Information |
                      | TI = Time Information       |
                      | UI = UL/DL Information      |
                      | ?? = Help Text              |
                      +-----------------------------+

Das sind alle möglichen Menüpunkte. Im Normalfall sehen Sie jedoch nie alle,
sondern nur jene, die Sie aufgrund Ihres User-Level ausführen können oder die
für die momentane Aktion sinnvoll sind.

Nachfolgend eine genaue Beschreibung der einzelnen Befehle:

CS = Chat SysOp                     Diese Funktion läßt die Glocke am BBS
                                    Rechner ertönen, um den SysOp zu rufen.
                                    Falls der SysOp bereit ist, befinden Sie
                                    sich auch gleich im Chat Modus, wo Sie Ihr
                                    Anliegen vorbringen können. Falls der SysOp
                                    aber nicht erreichbar ist, erhalten Sie
                                    eine entsprechende Meldung. Sie haben dann
                                    noch die Möglichkeit, eine Private Mail zu
                                    hinterlassen (SysOp User Number 5).

FU = Find User                      Mit diesem Befehl können Sie User suchen,
                                    wenn Sie nur einen Teil des Namens oder
                                    die User-Number wissen. Geben Sie die Zahl
                                    oder den gewünschten Suchbegriff ein. Danach
                                    erhalten Sie eine Liste aller User, deren
                                    Namen mit Ihrem Suchkriterium überein-
                                    stimmen.

LA = List all Users                 Mit diesem Befehl erhalten Sie eine Liste
                                    aller User dieser Box bestehend aus User-
                                    Number, User-Name, die Anzahl der Anrufe
                                    sowie Datum und Uhrzeit der letzten
                                    Session.

LI = Logoff Information             Mit diesem Befehl erhalten Sie Ihre letzte
                                    und aktuelle Baudrate sowie die Anzahl der
                                    Logins und die letzte Logoff Type.

MI = Message and Mail Info          Mit diesem Befehl erhalten Sie die Anzahl
                                    der von Ihnen gelesenen und geschriebenen
                                    Messages und Private Mails.

MM = Main Menu                      Mit diesem Befehl kommen Sie aus diesem
                                    Board wieder ins Main Menu.

SI = Security Information           Mit diesem Befehl erhalten Sie die Security
                                    Level für alle Hauptgruppen aufgelistet
                                    sowie Ihren Status angezeigt.

TC = Top Caller Information         Mit diesem Befehl erhalten Sie die 10 User
                                    mit den meisten Anrufen sortiert nach der
                                    Anzahl Ihrer Anrufe aufgelistet. Es werden
                                    zusätzlich die totale Online Zeit und die
                                    letzte Baudrate mit der der User online war
                                    angezeigt.

TI = Time Information               Mit diesem Befehl erhalten Sie folgende
                                    Zeiten angezeigt. Letzte Online Zeit,
                                    Connect Zeitpunkt, Aktuelle Uhrzeit, Totale
                                    Online Zeit, Zeit-Limit und aktuell ver-
                                    brauchte Online Zeit.

UI = UL/DL Information              Mit diesem Befehl erhalten Sie Informationen
                                    zum Upload und Download. Die Wirkungsweise
                                    und das Verhältnis des Ratio, die Anzahl der
                                    UL und DL sowie die übertragenen Bytes und
                                    die durchschnittliche Übertragungsrate in
                                    Zeichen pro Sekunde.

?? = Help Text                      Mit diesem Befehl erhalten Sie online den
                                    Help Text, den Sie eben gelesen haben.

So jetzt haben Sie es geschafft. Sie sind nun als New User angemeldet und
können ab dem nächsten Mal mit Ihrem eigenen User Namen einsteigen.

Nun können Sie im SetUp Menu Ihre persönlichen Einstellungen vornehmen
die dann automatisch bei jedem Neueinstieg eingestellt werden.

Die wichtigsten Einstellungen die überprüft werden sollten sind:

1. Change Lines ( Anzahl der darstellbaren Zeilen Ihres Terminalprogrammes )
2. Change Emulation ( TTY, TTY+CLS, VT100/ANSI, VT100/ANSI+CLS )
3. Change Help Text ( kann auch bei OFF mit ? oder Enter aufgerufen werden )
4. Change Transfer ( Up- und Download Protokoll getrennt einstellbar )
5. Change List Form ( Sortierfolge von List Files im BM, MB, FS und PM)

Bei Problemen bzw. Fragen zum Programm oder zur Bedienung rufen Sie den
SysOp über CS oder schreiben Sie ihm eine Private Mail.

Auch Kritik und Anregungen werden gerne angenommen.

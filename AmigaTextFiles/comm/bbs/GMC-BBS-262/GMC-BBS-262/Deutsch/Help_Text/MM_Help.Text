Das sind alle möglichen Menüpunkte. Im Normalfall sehen Sie jedoch nie alle,
sondern nur jene, die Sie aufgrund Ihres User-Level ausführen können oder die
für die momentane Aktion sinnvoll sind.

Nachfolgend eine genaue Beschreibung der einzelnen Befehle:

BM = Bulletins Menu     Hier stehen Informationen über das Programm und
                        wichtige Hinweise zu neuen Updates. Schauen Sie von
                        Zeit zu Zeit mal da rein um sich zu informieren was
                        es Neues gibt. Weiters sind hier aktuelle Informationen
                        zu verschiedenen Themen zu finden. Die Angebote werden
                        in dieser Area ausschließlich vom SysOp betreut. Für den
                        Zugang zu diesem Board ist ein Security Level von min-
                        destens 10 erforderlich.

CB = Call Back          Diese Funktion ist nur für bestimmte User möglich. Sie
                        können hier in 2 Zeilen das Modem konfigurieren und
                        eine Nummer angeben, unter der sie vom BBS Programm
                        direkt nach dem Logoff zurückgerufen werden.

CS = Chat SysOp         Diese Funktion läßt die Glocke am BBS Rechner ertönen,
                        um den SysOp zu rufen. Falls der SysOp bereit ist, be-
                        finden Sie sich auch gleich im Chat Modus, wo Sie Ihr
                        Anliegen vorbringen können. Falls der SysOp aber nicht
                        erreichbar ist, erhalten Sie eine entsprechende Meldung.
                        Sie haben dann noch die Möglichkeit, eine Private Mail
                        zu hinterlassen (SysOp User Number 5).

EU = Edit Users         Dieser Menüpunkt ist nur für den SysOp und eventuelle
                        Co-SysOps verfügbar. Hier können die genauen Userdaten
                        angezeigt (Einträge aus Join as a Member - siehe auch
                        dort) sowie entsprechende Security-Level vergeben
                        werden. Letztere regeln Ihre Zugriffsrechte auf die
                        einzelnen Areas. Desweiteren werden hier User aktiviert,
                        deaktiviert, validated oder gelöscht.

FS = File System        Im File System befinden sich alle verfügbaren Files,
                        gegliedert in verschiedene Areas, zum up- und down-
                        loaden. Die Möglichkeit für diese Aktionen ist vom
                        individuellen Security-Level abhängig. Ist dieser zu
                        niedrig, wird der Zugriff verweigert. Die Files sind
                        meist mit Kommentaren zum Inhalt versehen. Weiters
                        können eventuell vorhandene "Doc.Files" online gelesen
                        werden. Für den Zugang zu diesem Board ist ein Security
                        Level von mindestens 10 erforderlich.

GB = Goodbye            Mit dieser Funktion wird das Logoff aus der Mailbox
                        veranlaßt und das Modem legt auf.

JM = Join as a Member   Hier können Sie sich als User identifizieren. Das ist
                        notwendig, um sinnvoll in der Box arbeiten zu können.
                        Bitte beantworten Sie alle Fragen, da Sie sonst nicht
                        als User validatet und aktiviert werden. Der SysOp wird
                        nach Prüfung Ihren Security-Level festsetzen. Dieser
                        kann später auch erhöht oder reduziert werden, um Ihnen
                        mehr oder weniger Zugriffsrechte zu geben.

MB = Message Board      Hier können Nachrichten an alle User verfaßt oder
                        solche von anderen Usern gelesen werden. Diese Aktionen
                        sind ebenfalls vom Security-Level abhängig. Die Files
                        sind meist mit Kommentaren zum Inhalt versehen. Für den
                        Zugang zu diesem Board ist ein Security Level von min-
                        destens 10 erforderlich.

MR = Modem Report       Mit dieser Funktion kann das Mailboxmodem abgefragt
                        werden. Je nach Konfiguration der Mailbox und des
                        verwendeten Modemtyps sind verschiedenste Modem
                        Parameter sowie Modemdaten abrufbar. Daraus kann man
                        auf mögliche Leitungs oder Connect Probleme schließen.

MS = Mail to SysOp      Mit dieser Funktion haben Guest User die Möglichkeit,
                        direkt an den SysOp eine Private Mail zu schreiben.

PM = Private Mail       Private Mail dient dazu, Meldungen an bestimmte User
                        oder den SysOp zu schreiben bzw. erhaltene Mails zu
                        lesen. Ist neue Mail vorhanden, erscheint beim Login
                        die Anzahl der neuen Private Mails. Für den Zugang zu
                        diesem Board ist ein Security Level von mindestens 10
                        erforderlich.

SM = Setup Menu         Grundeinstellungen wie Emulation, Zeilenanzahl, Art des
                        Help Text, List Form, Übertragungsprotokoll für Up- und
                        Downloads sind hier zu fixieren. Sie können Ihr Passwort
                        ändern bzw. erhalten Sie sämtliche persönlichen Infos.
                        Für den Zugang zu diesem Menu ist ein Security Level
                        von mindestens 10 erforderlich.

SS = System Statistic   Hier erhalten Sie einige Infos über die Mailbox wie
                        z. B.  wann sie das erste Mal in Betrieb genommen
                        wurde, wie lange sie effektiv gelaufen ist, wie lange
                        sie online genutzt wurde, wieviele Anrufe via Fax und
                        von Usern als Guest, New User oder Valid User getätigt
                        wurden, die Anzahl der Up- und Downloads bzw. der
                        Messages und Private Mails.

UM = User Menu          Hier können Sie abfragen, wieviele User in der Box
                        bereits registriert sind, deren User-Number, den Namen
                        sowie die Zeit des letzten Einstiegs.
                        Wenn Sie z. B. die Nummer eines Users wissen, können
                        Sie hier auch seinen Namen erfahren oder umgekehrt.
                        Desweiteren werden hier sämtliche statistische Daten
                        angezeigt die sonst noch erfaßt und verfügbar sind.
                        Für den Zugang zu diesem Menu ist ein Security Level
                        von mindestens 10 erforderlich.

?? = Help Text          Mit diesem Befehl erhalten Sie online den Help Text, den
                        Sie eben gelesen haben.

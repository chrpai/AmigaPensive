                  |           Bulletins Menu           |
                  |           ~~~~~~~~~~~~~~           |
                  | CA = Change Area                   |
                  | CD = Change Directory              |
                  | CS = Chat SysOp                    |
                  | DE = Delete Directories or Files   |
                  | LI = List Directories and Files    |
                  | MD = Make Directories              |
                  | MM = Main Menu                     |
                  | RB = Read Bulletin                 |
                  | RE = Rename Directories or Files   |
                  | SC = Set Directory or File Comment |
                  | WB = Write Bulletin                |
                  | ?? = Help Text                     |
                  +------------------------------------+

Das sind alle möglichen Menüpunkte. Im Normalfall sehen Sie jedoch nie alle,
sondern nur jene, die Sie aufgrund Ihres User-Level ausführen können oder die
für die momentane Aktion sinnvoll sind.

Nachfolgend eine genaue Beschreibung der einzelnen Befehle:

CA = Change Area                    In den einzelnen Areas werden die Files
                                    thematisch zusammengefaßt. Mit Eingabe von
                                    CA erhalten Sie die Liste der vorhandenen
                                    Areas mit Laufnummer und kurzer Inhaltsbe-
                                    schreibung. Außerdem wird der Security-Level
                                    angezeigt, der zum Zugang in die Areas
                                    mindestens benötigt wird. Danach erscheint
                                    eine Eingabeaufforderung für die Nummer der
                                    gewünschten Area.

CD = Change Directory               Mit diesem Befehl ist es möglich in ein
                                    Unterverzeichnis zu wechseln. Da hier die
                                    Eingabe des Dir-Namens verlangt wird, ist
                                    es notwendig zuerst ein List durchzuführen.
                                    Nun werden Sie aufgefordert, den Namen des
                                    Directories einzugeben, in das verzweigt
                                    werden soll.

CS = Chat SysOp                     Diese Funktion läßt die Glocke am BBS
                                    Rechner ertönen, um den SysOp zu rufen.
                                    Falls der SysOp bereit ist, befinden Sie
                                    sich auch gleich im Chat Modus, wo Sie Ihr
                                    Anliegen vorbringen können. Falls der SysOp
                                    aber nicht erreichbar ist, erhalten Sie
                                    eine entsprechende Meldung. Sie haben dann
                                    noch die Möglichkeit, eine Private Mail zu
                                    hinterlassen (SysOp User Number 5).

DE = Delete Directories or Files    Hier können Sie Directories oder Files
                                    löschen. Nach Eingabe des ensprechenden
                                    Namens erhalten Sie eine Meldung über den
                                    Erfolg oder Mißerfolg des Löschvorganges.
                                    Um diese Aktion ausführen zu können, ist
                                    ein Security_Level von mindestens 90
                                    notwendig.

LI = List Directories and Files     Dieser Befehl listet alle Directories und
                                    Files mit Beschreibung (wenn vorhanden) in
                                    der gewünschten Reihenfolge ab einem be-
                                    liebigem Datum je nach Ihrer Wahl. Zuerst
                                    werden die Directories aufgelistet, welche
                                    mit einem + vor dem Namen gekennzeichnet
                                    sind. Dann folgen die Files mit einem - vor
                                    dem Namen.

MD = Make Directories               Mit diesem Befehl ist es möglich, ein neues
                                    Directory anzulegen. Nach Eingabe des neuen
                                    Directory-Namens erscheint eine Meldung über
                                    Erfolg oder Mißerfolg dieser Aktion.
                                    Desweiteren erscheint eine Eingabeauf-
                                    forderung für eine Beschreibung des
                                    Directories, diese kann aber mit Enter
                                    übergangen werden. Für die Durchführung ist
                                    ein Security-Level von mindestens 60 nötig.

MM = Main Menu                      Mit diesem Befehl kommen Sie aus diesem
                                    Board wieder ins Main Menu.

RB = Read Bulletin                  Mit diesem Befehl können Sie vorhandene
                                    Bulletins lesen. Da hier die Eingabe des
                                    File-Namens verlangt wird, ist es notwendig,
                                    zuerst ein List durchzuführen.

RE = Rename Directories or Files    Dieser Befehl dient zum Ändern von
                                    Directory- oder File-Namen. Zuerst wird die
                                    Eingabe des alten Namens verlangt, danach
                                    die des neuen Namens. Für diese Aktion ist
                                    ein Security-Level von mindestens 70
                                    erforderlich.

SC = Set Directory or File Comment  Mit diesem Befehl kann man die Beschreibung
                                    zu den Directories und Files bearbeiten, das
                                    heißt ändern, löschen oder ergänzen. Nach
                                    Eingabe des entsprechenden Directory- oder
                                    File-Namens kann eine neue Beschreibung
                                    eingegeben werden. Für die Durchführung ist
                                    ein Security-Level von mindestens 40 nötig.

WB = Write Bulletin                 Nach Eingabe des File-Namens und der
                                    Beschreibung kann das Bulletin erfaßt
                                    werden. Diese Aktion erfordert einen
                                    Security-Level von mindestens 50.

?? = Help Text                      Mit diesem Befehl erhalten Sie online den
                                    Help Text, den Sie eben gelesen haben.

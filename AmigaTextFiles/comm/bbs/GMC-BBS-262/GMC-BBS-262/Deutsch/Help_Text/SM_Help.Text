Das sind alle möglichen Menüpunkte. Im Normalfall sehen Sie jedoch nie alle,
sondern nur jene, die Sie aufgrund Ihres User-Level ausführen können oder die
für die momentane Aktion sinnvoll sind.

Nachfolgend eine genaue Beschreibung der einzelnen Befehle:

CE = Change Emulation     Bei diesem Menüpunkt können Sie die Bildschirmanzeige
                          auf Ihrem Monitor einstellen. Bei TTY erscheint die
                          Ausgabe einfärbig, es werden sämtliche Farb- und
                          Schriftattribute ausgefiltert, bei VT100/ANSI sind
                          sowohl Farb- als auch Schriftattribute möglich. Wenn
                          Sie zusätzlich CLS aktivieren, wird der Bildschirm
                          automatisch nach jeder vollen Seite gelöscht. Das ist
                          vor allem bei langsamen Rechnern zu empfehlen, da der
                          Bildschirmaufbau beschleunigt wird. Haben Sie keine
                          Einstellung vorgenommen, wird standardmäßig im TTY
                          Modus dargestellt.

CF = Change List Form     Mit diesem Befehl ist es möglich aus den 18 ver-
                          schiedenen List Formen eine auszuwählen, die dann
                          automatisch bei jedem List vorgeschlagen wird. Dieser
                          Vorschlag kann aber trotzdem beim List individuell
                          geändert werden.

CH = Change HelpText      Mit diesem Befehl kann die Art der Anzeige des Help
                          Text geändert werden. Der Help Text erscheint bei
                          jeder Menüeingabezeile entweder gar nicht, als Buch-
                          stabenkombination oder als vollständiges Menü. Auch
                          wenn die Anzeige ausgeschaltet ist oder nur die
                          Buchstabenkombination erscheint, kann man durch Enter
                          den vollen Help Text abrufen. Wenn Sie keine Ein-
                          stellung vornehmen, wird standardmäßig der volle Help
                          Text angezeigt.

CL = Change # of Lines    Hier kann die Anzahl der am Bildschirm darstellbaren
                          Zeilen eingegeben werden. Enthält die aufgerufene
                          Information mehr Zeilen als eingestellt, erscheint am
                          unteren Bildschirmrand "More [Y/n] : ". Haben Sie
                          keine Zahl eingegeben, werden standardmäßig 23 Zeilen
                          angezeigt.

CS = Chat SysOp           Diese Funktion läßt die Glocke am BBS Rechner er-
                          tönen, um den SysOp zu rufen. Falls der SysOp bereit
                          ist befinden Sie sich auch gleich im Chat Modus, wo
                          Sie Ihr Anliegen vorbringen können. Falls der SysOp
                          aber nicht erreichbar ist, erhalten Sie eine ent-
                          sprechende Meldung. Sie haben dann noch die Möglich-
                          keit, eine Private Mail zu hinterlassen (SysOp User
                          Number 5).

CT = Change Transfer      Mit diesem Befehl legen Sie das Übertragungsprotokoll
                          für Up- und Downloads fest. Nach Eingabe des Befehls
                          werden die möglichen Upload-Protokolle, versehen mit
                          einer Laufnummer angezeigt. Nach Eingabe einer Nummer
                          werden in gleicher Weise die möglichen Download-
                          Protokolle aufgelistet. Wird hier keine Einstellung
                          getroffen, so können auch keine Up- und Downloads
                          durchgeführt werden.

EC = Edit Computer        Mit diesem Befehl können Sie Ihre Angaben bezüglich
                          des Computer Equipments ändern. Dies dient zur Infor-
                          mation für den SysOp.

EE = Edit Email Address   Mit diesem Befehl können Sie Ihre Email Adresse
                          ändern. Diese Information dient nur zur Information
                          für den SysOp.

EM = Edit Modem           Mit diesem Befehl können Sie Ihre Angaben bezüglich
                          der Modem Type und Geschwindigkeit ändern. Dies dient
                          zur Information für den SysOp.

EP = Edit Password        Dieser Befehl ermöglicht das Ändern Ihres Passwortes.
                          Nach Eingabe des Befehls, werden Sie aufgefordert,
                          ein Passwort einzugeben, wobei Ihr altes Passwort
                          angezeigt wird.

MM = Main Menu            Mit diesem Befehl kommen Sie aus diesem Board wieder
                          ins Main Menu.

SS = Show Setup           Mit dieser Funktion erhalten Sie Ihre persönlichen
                          Daten angezeigt, d. s. alle Daten die Sie bei Join as
                          a Member eingegeben haben sowie Anzahl der Zeilen,
                          die Emulation, Art des Help Text, List Form und das
                          eingestellte Übertragungsprotokoll für Up- und Down-
                          load.

?? = Help Text            Mit diesem Befehl erhalten Sie online den Help Text,
                          den Sie eben gelesen haben.

                       |       ~~~~~~~~~~~~        |
                       | CS = Chat SysOp           |
                       | DE = Delete Private Mails |
                       | LI = List Private Mails   |
                       | MM = Main Menu            |
                       | RP = Read Private Mail    |
                       | WP = Write Private Mail   |
                       | ?? = Help Text            |
                       +---------------------------+

These are all possible points in the menu. Normally you only see the points
which you can execute because of your user level or which make sense for the
current action.

In the following you find an exact description of the several commands:

CS = Chat SysOp                     This function makes a bell ringing on the
                                    BBS host to call the sysop. If the sysop is
                                    ready you find yourself in the chat mode.
                                    If the sysop is not available you get a
                                    message. Now you can leave a private mail
                                    to him (sysop user number 5).

DE = Delete Private Mails           Here you can delete private mails which you
                                    have already read. After you have entered
                                    the respective name you get a message if
                                    you were successful.

LI = List Private Mails             With this command you get a list of all
                                    private mails with description (if avail-
                                    able) in the requested order.

MM = Main Menu                      With this command you can get back from
                                    this board to the main menu.

RP = Read Private Mail              With this command you can read all avail-
                                    able mails. Because you have to enter the
                                    file name you need to make a list.

WP = Write Private Mail             With this command you can write private
                                    mails to another user or to the sysop.
                                    First you have to enter the user number
                                    of the addressee and after that the
                                    descripton. Now you can write your mail.

?? = Help Text                      With this command you can get this help
                                    text online.

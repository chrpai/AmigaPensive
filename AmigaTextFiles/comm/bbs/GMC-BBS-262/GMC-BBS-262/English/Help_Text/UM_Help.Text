These are all possible points in the menu. Normally you only see the points
which you can execute because of your user level or which make sense for the
current action.

In the following you find an exact description of the several commands:

CS = Chat SysOp                     This function makes a bell ringing on the
                                    BBS host to call the sysop. If the sysop is
                                    ready you find yourself in the chat mode.
                                    If the sysop is not available you get a
                                    message. Now you can leave a private mail
                                    to him (sysop user number 5).

FU = Find User                      With this command you can search users if
                                    you know only a part of the user name or
                                    only the user number. Enter the requested
                                    search term. You get a list of all corres-
                                    ponding users.

LA = List all Users                 With this command you get a list of all
                                    users of this box with user-number, user
                                    name, number of calls and date and time of
                                    the last session.

LI = Logoff Information             With this command you get your last and
                                    your current baud rate, the number of your
                                    logins and the last logoff type.

MI = Message and Mail Info          With this command you get the number of
                                    all messages and private mails read and
                                    written by you.

MM = Main Menu                      With this command you can get back from
                                    this board to the main menu.

SI = Security Information           With this command you get a list of the
                                    security_level for all areas and an
                                    information about your status.

TC = Top Caller Information         With this command you get a ranking of the
                                    10 users which called most. Moreover the
                                    the total online time and the user´s last
                                    baud rate is shown.

TI = Time Information               With this command you get the following
                                    times: last online time, connect time,
                                    current time, total online time, time limit
                                    and actual used time.

UI = UL/DL Information              With this command you get information
                                    concerning up- and downloads, the mode
                                    and the rate of the ratio, the number of
                                    up- and downloads, the transfered bytes and
                                    the average transfer rate in bytes per
                                    second.

?? = Help Text                      With this command you can get this help
                                    text online.

These are all possible points in the menu. Normally you only see the points
which you can execute because of your user level or which make sense for the
current action.

In the following you find an exact description of the several commands:

CA = Change Area                    In the several areas there are files with
                                    the same topic. Entering CA you get a
                                    listing of all the areas with number and
                                    short summary. Moreover the security_level
                                    which is at least required for up- or down-
                                    loads is shown. The two values can be
                                    different. To get into the respective area
                                    one of them will do. After that you get a
                                    prompt for the number of the area wanted.

CD = Change Directory               With this command you can change to a sub-
                                    directory. Here you have to know the name
                                    of the directory. So it is necessary to
                                    make a list first. Now you are prompted
                                    to enter the name of the respective sub-
                                    directory.

CS = Chat SysOp                     This function makes a bell ringing on the
                                    BBS host to call the sysop. If the sysop is
                                    ready you find yourself in the chat mode.
                                    If the sysop is not available you get a
                                    message. Now you can leave a private mail
                                    to him (sysop user number 5).

DE = Delete Directories or Files    This command deletes directories or files.
                                    After you have entered the respective name
                                    you get a message if you were successful.
                                    To be able to do this you need at least
                                    security_level 90.

DL = Download Files                 With this command you can download files
                                    from the mailbox. You get a pompt for the
                                    file name(s). The number of the files which
                                    can be entered is dependent on your
                                    transfer protocol.
                                    Notice: For 3 Downloads you need to make
                                    1 upload.

ES = Execute Script                 With this command it is possible to start
                                    a script file e.g. to create filelists or
                                    pack files and so on. The mailboxprogram
                                    waits until the script has finished and
                                    informs the user about this. For this
                                    action you need at least security_level 80.

LI = List Directories and Files     With this command you get a listing of all
                                    directories and files with description (if
                                    available) in a requested order. At first
                                    the directories are listed with a + before
                                    the name followed by the files with a -
                                    before the name.

MD = Make Directories               With this command you can make directories.
                                    After you have entered the new directory
                                    name you get a message if you were success-
                                    ful. After that you get a prompt for a
                                    description of the directory but you can
                                    go on with enter. For this action you need
                                    at least security_level 60.

MM = Main Menu                      With this command you can get back from
                                    this board to the main menu.

PF = Pack Files                     With this command you can pack files online
                                    with LHA. It is possible to pack up to ten
                                    files. Because the files names have to be
                                    entered it will be necessary to make a
                                    list previously. You will find the packed
                                    file pf1.lha in the directory temp. For this
                                    action you need at least security_level 30.

RE = Rename Directories or Files    With this command you can change the name
                                    of a directory or file. First you have to
                                    enter the current name. After this the new
                                    name is asked. To be able to do this you
                                    need at least security_level 70.

RF = Read Files                     With this command you can read doc files
                                    which are possibly available. Moreover it
                                    is possible to list the content of *.lha or
                                    *.lzh files. Because you have to enter the
                                    file name it will be necessary to make a
                                    list previously.

SC = Set Directory or File Comment  With this command you can modify, delete or
                                    complete the descriptions of the director-
                                    ies or files. After entering the respective
                                    directory or file name a new description
                                    can be written. To be able to do this you
                                    need at least security_level 40.

UL = Upload Files                   With this command you can send your files
                                    the mailbox. How many files you can send
                                    with one upload depends on your transfer
                                    protocol e.g. using x-modem you have to
                                    enter the file name and the description
                                    before transfer, using z-modem you will be
                                    asked for the description of the files
                                    after transfer. If no description is given
                                    the system inserts the respective user name
                                    and the user number automatically.
                                    Notice: For 1 upload you can get 3 down-
                                    loads maximally.

?? = Help Text                      With this command you can get this help
                                    text online.

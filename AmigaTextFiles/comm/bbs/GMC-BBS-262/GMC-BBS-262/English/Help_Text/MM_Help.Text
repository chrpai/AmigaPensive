These are all possible points in the menu. Normally you only see the points
which you can execute because of your user level or which make sense for the
current action.

In the following you find an exact description of the several commands:

BM = Bulletins Menu     Here you find information about the program and
                        important references to new updates. Look in this
                        menu from time to time to get some news. Moreover here
                        you can find actual information on several topics.
                        The offers in this areas will only be handled by the
                        sysop. To be able to get into this board you need at
                        least security_level 10.

CB = Call Back          Only a few special users can use this function. They
                        can send in 2 lines a configuration to the modem and
                        give the BBS program a telephone number to be called
                        back directly after the logoff.

CS = Chat SysOp         This function makes a bell ringing on the BBS host to
                        call the sysop. If the sysop is ready you find your-
                        self in the chat mode. If the sysop is not available
                        you get a message. Now you can leave a private mail to
                        him (sysop user number 5).

EU = Edit Users         This function is only available for the sysop and
                        possible co-sysops. Here are the complete user data
                        shown (data from Join as a Member - see also there) and
                        the security_level are given out. Security_level are
                        regulating your access to the several areas. Users will
                        be activated, deactivated, validated or deleted.

FS = File System        In the file system are all available files situated,
                        structured in several areas, ready for uploads and
                        downloads. The possibility of this action is dependent
                        on the security_level you have. If it is to low the
                        access will be denied. In most cases the files have
                        comments to their content. You can online read `doc.
                        files´ if available. For the access to this board you
                        need at least security_level 10.

GB = Goodbye            With this function the logoff will be initiated and
                        the modem hooks off.

JM = Join as a Member   Here you can identify yourself as an user. This is
                        necessary for correct working in the box. Please
                        fill in all fields. In other case you could not be
                        validated and activated as user. The sysop will check
                        the data and settle your security_level. This could be
                        raised and reduced in the future to give you more or
                        less rights.

MB = Message Board      Here you can write messages to all users or read some
                        from other users. The possibility of this action is
                        also dependent on your security_level. In most cases
                        the files have comments to their content. For the
                        access to this board you need at least security_level
                        10.

MR = Modem Report       With this function you can query the mailboxmodem.
                        Depending on the configuration of the mailbox and the
                        used modem there are different modem parameter and
                        modem settings fetchable. From this you can explain
                        possible line conditions or Connect failures.

MS = Mail to SysOp      With this function guest users have the chance to write
                        a Private Mail to the sysop directly.

PM = Private Mail       With this function you can write mail to one ore more
                        special users or the sysop and you can read received
                        mail. Is there new mail available you get their number
                        after login. For the access to this board you need at
                        least security_level 10.

SM = Setup Menu         General settings such as emulation, number of lines,
                        type of Help Text, List Form, Transfer Protocol for
                        Up- and Downloads have to be fixed here. You can change
                        your password and you get all personal information.
                        For the access to this menu you need at least
                        security_level 10.

SS = System Statistic   Here you get some information about the mailbox e.g.
                        date of first start, total time, total online time,
                        how many fax calls, how many calls from users as Guest,
                        New User or Valid User, the number of up- and downloads
                        or messages and private mails.

UM = User Menu          Here you can see how many users are already registrated
                        in the box, their user number, the name and the last
                        login. If you know e.g. an user number you can get the
                        respective name and vice versa. Moreover here are shown
                        all available statistics.

?? = Help Text          With this command you can get this help text online.

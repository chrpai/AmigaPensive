These are all possible points in the menu. Normally you only see the points
which you can execute because of your user level or which make sense for the
current action.

In the following you find an exact description of the several commands:

CE = Change Emulation     Here you can set the display of your monitor. Using
                          TTY your display is monochrom without color and font
                          attributes. Using VT100/ANSI all color and font
                          attributes are possible. If you have CLS activated,
                          the screen will be cleared after each full page.
                          This would be recommendable on slow computers
                          because the screen speed will be increased. If you
                          have made no setup the default mode is TTY.

CF = Change List Form     With this command you can choose one of 18 different
                          list forms which will be automatically proposed on
                          each list. Never the less the proposal can be
                          changed on each individual list.

CH = Change HelpText      With this command you can change the type of help
                          text. The help text is either not shown on the input
                          line or as a combination of letters or as full menu.
                          Even if the help text is off or as combination of
                          letters you can call the full menu by pressing
                          enter. If you don`t have made a setup the full help
                          text will be displayed.

CL = Change # of Lines    Here you can insert the number of lines on the
                          screen. If the file listing has more than the de-
                          fined lines you will be asked "More [Y/n] : ".
                          If you don`t have a number defined the default value
                          is 23 lines.

CS = Chat SysOp           This function makes a bell ringing on the BBS host
                          to call the sysop. If the sysop is ready you find
                          yourself in the chat mode. If the sysop is not
                          available you get a message. Now you can leave a
                          private mail to him (sysop user number 5).

CT = Change Transfer      With this command you define the transfer protocol
                          for up- and downloads. After you have entered CT
                          all possible upload protocols will be listed. When
                          you have entered the respective number the protocols
                          for downloads will be listed in the same way. If you
                          don`t have made any setups no up- and downloads will
                          be executed.

EC = Edit Computer        With this command you can edit your statements
                          concerning your computer equipment. It serves to
                          inform the sysop.

EE = Edit Email Address   With this command you can edit your email address.
                          It serves to inform the sysop.

EM = Edit Modem           With this command you can edit your settings
                          concerning the modem type and speed. It serves to
                          inform the sysop.

EP = Edit Password        This command allows you to edit your password.
                          You will be requested to insert a password, your
                          former password will be shown.

MM = Main Menu            With this command you can get back from this board
                          to the main menu.

SS = Show Setup           With this function you can display all your personal
                          data which you have inserted at Join as a Member,
                          the number of lines, the emulation, the type of help
                          text, list form and the transfer protocols for up-
                          and download.

?? = Help Text            With this command you can get this help text online.

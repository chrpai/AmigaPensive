                             =====================

You have made it! Now you are registrated as New User and on the next login you
can use your own User Name.

Make your personal settings in the setup menu which will be set for you on each
new login.

The most important settings which need to be checked from you:

1. Change Lines (number of lines from your terminal program)
2. Change Emulation (TTY, TTY+CLS, VT100/ANSI, VT100/ANSI+CLS )
3. Change Help Text (available with ? or return when the setting is OFF)
4. Change Transfer (up- and Download protocol can be defined seperately)
5. Change List Form (sort mode of List Files in the BM, MB, FS and PM)

If you have some problems or questions concerning the program or handling
call the sysop or write a private mail to him.

Criticism or good ideas will certainly be accepted.

Have a nice day and much fun in the mailbox.

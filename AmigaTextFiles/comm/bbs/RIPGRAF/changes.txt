RIPGRAF CHANGES

0.91 - 23 Apr 1995

-Fixed a problem with "standard" text printing using complement.

-Added a version number string.


0.90 - 04 Feb 1995

-Added object resizing, let me know if you have any problems using it.
 Note, you can force a object drag by hitting the SHIFT key while
 clicking on an object, this was added for objects so small that no
 matter where you click you select a handle and the program thinks
 you want to resize rather than drag it.

 NOTE: The resizing isn't working perfectly yet, no matter which handle
 you grab it is treated as though it was the lower right handle. You
 cannot resize objects negatively (flip it on it's axis).

-Added a new editing feature. If one or more objects are selected you
 can change the colors by clicking on the palette, you can change the
 line thickness by clicking on either thickness gadgets and you can
 change the fill pattern. You can't change button colors this way, you
 must use the button requester (double-click on the button).

-Added a palette requester. It allows you select a color either using
 the three RGB sliders or by the EGA color number. There are only 64
 colors available in the EGA palette (each color register has four
 possible settings; Off, 1/3 Bright, 2/3 Bright, and Bright) 4x4x4=64
 The rip slider is good for noting useful colours (skin color is 39
 for example)

-Palette requester color order re-arranged from 0.90beta

-You can enter ESC characters in the rip file prefix/suffix by typing
 a "^" (shift 6) character where ever a Escape char ($1B) is need. The
 "~" character is also used to signify an end of line (write a CR and
 a LF)

-The right mouse button can be used for selecting the background color
 in the toolbar, the left mouse button is used for selecting the forground
 color. You no longer have to click on those two color gadgets (foreground
 and background) before selecting a color. If your familiar with using
 DPaint and other bitmap paint programs this should be a more comfortable
 method of selecting colors (I know it was for me).

-The right mouse button (when not over the color palette gadget) can
 be used in the toolbar to toggle from the edit tools to drawing tools
 and will back you out of sub-tools (instead of clicking on the 'Back'
 gadget)

-Added a menu option to ALWAYS display the location and size of the text
 window. Go to the 'Tools' menu and select the "Text Window Display"

-Fixed the problem RIPTERM (the IBM program) had with wrap around characters
 in text commands (like RIP_TEXT & RIP_BUTTON). The program will now
 _NEVER_ split a text string in two with a wrap around character.

-Added a requester to show which tools are not functional yet.

-Fixed the menu command key function. It now works for everything in the
 menu while the mouse is on the drawing area.

-Added an "are you sure" requester when you quit. This will only occur if
 some objects are onscreen. You can either quit, save then quit
 or cancel.

-Added a a load requester which will appear when objects are already
 onscreen. You have the option to 'clear the screen first', 'append to' or
 'cancel'. Appending means that whatever you load will be added to the
 END of the object already loaded (it will appear that the new objects
 are drawn over top of the existing objects)

==========================================================================
0.82 - 30 Nov 1994

Fixed the problem some people had while loading rip files with text
to close to the top of the screen. RIPGRAF was creating negative
coords. It will now not allow you to put text off the top of the screen.

==========================================================================
0.81 UPDATE - 11 Oct 1994

Fixed the problem with underline hotkey flag (for buttons) not being saved.

Fixed the problem with the .ICN extension in buttons being shortened to
.IC when you save (after a load)

Fixed the problem with button label orientations reverting to "center"
after loading.

    Introduction.
    ~~~~~~~~~~~~~

 As you will probably already know, MasterMind is a game in which the player
 must guess a random colourcode. The player has ten guesses to crack the code.
 After each guess the computer will give you a hint that shows how close you
 were to the right colourcode.

 MastE!rMind maintains a list of the ten highest scores. This score depends
 on the number of tries in which the right code was guessed and on the
 required time to do so.


    Installation.
    ~~~~~~~~~~~~~

 The default-path where this door should be installed is Doors:MastE!rMind/
 If you want to install it in a different directory then you have to edit
 the MastE!rMind-script and change the 'path'-setting at the top of the
 script (make sure that the path-specification ends with a '/' or a ':' ).

 Now go to the doors area on your BBS and add MastE!rMind as a ARexx door.

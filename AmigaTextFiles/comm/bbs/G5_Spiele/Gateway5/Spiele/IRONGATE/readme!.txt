
                  --------------------------------------
                      IMPORTANT MESSAGE FOR USERS OF
                     The Lords of Irongate Adventure!
                  --------------------------------------


NOTE: v1.xx and v2.xx use a DIFFERENT DATA FILE format. Player characters
      from a v1.xx release CANNOT be used/transfered to the v2.xx release!


1)   To get QUICK command line help for running IRONGATE type the following
     command from a dos shell:

       IRONGATE ?

2)   You must ASSIGN IRONGATE: to the location where all the files are
     installed, ie..  ASSIGN IRONGATE: DH0:IRONGATE


3)   The CRITICAL files YOU NEED to run the program include:

     IRONGATE           <- The main executable file for the game
     CHANGES.TXT        <- Irongate revision and release history information
     IRONGATE.DOC       <- The complete documentation file
     MONSTERS.DAT       <- Monsters DATA file
     ITEMS.DAT          <- Items DATA file

     LOICOVER.ANS       <- ANSI COLOR text Cover picture
     LOIHELP.ANS        <- ANSI COLOR text online Help document
     LOIHINTS.ANS       <- ANSI COLOR text online Hints document
     LOIABOUT.ANS       <- ANSI COLOR text online About document
     LOIHIST.ANS        <- ANSI COLOR text of Quest History

     LOICOVER.TXT       <- TEXT (NO ANSI) Cover picture
     LOIHELP.TXT        <- TEXT (NO ANSI) online Help document
     LOIHINTS.TXT       <- TEXT (NO ANSI) online Hints document
     LOIABOUT.TXT       <- TEXT (NO ANSI) online About document
     LOIHIST.TXT        <- TEXT (NO ANSI) text of Quest History

     Additional files which are created as needed by The Lords of Irongate
     include (These files you may not have and don't need to start). In
     fact, if you are upgrading from a previous version it is recommended
     that you only copy the above (.EXE, .CFG and LOI??????.* files)
     over so as not to destroy any of your current players.

     PLAYERS.DAT        <- Binary file containing the players information
     HISCORES.ANS       <- ANSI COLOR text with the top 10 scores
     HISCORES.TXT       <- TEXT (NO ANSI CODES) of the top 10 scores

     Other files which may be included in an archive (DEMO) and/or the
     registered disk copy but are not needed for the game to run:

     README.TXT         <- Last minute IMPORTANT! installation instructions
     FILE_ID.DIZ        <- Auto file identification file
     REGISTER.TXT       <- Registration form
     LOISTART           <- SAMPLE Startup Script file for some BBS systems


4)   ENJOY!

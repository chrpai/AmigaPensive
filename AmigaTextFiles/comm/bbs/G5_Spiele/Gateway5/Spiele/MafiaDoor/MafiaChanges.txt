MafiaDoor Bug Fixes and Changes:
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

>>>>>>>>>>>>>>>>>>>> Fixes before Dec-1-91
The game should no longer mess up the old news file by placing the
current date at the top of the file if a player who is out of turns
is the first player of the day.

Incorrect (random) information was displayed if a player attacked
another don and lost. This was due to an error in a printf statement
and has been fixed.

Added re-draw screen to the menus (but not elsewhere).

Removed auto-capitalization of first letter of players name. This was
sometimes causing problems for some players.
--------------------------------------------------------------------------
There is now a $100M ceiling on cash.

A player will no longer be sent to court if he is already in jail.

Changed payments/income levels to make cash a little scarcer. Players
were getting too much money, and didn't have enough to spend it
on. More things to spend money on will be added in a future version
(I don't know what yet).

Fixed (hopefully) rare bug that sometimes resulted in negative numbers.

Changed scoring because the numbers were too big. The game does not use
the scores anyway, they are there in case the sysop wishes to use them
to decide when to end the game.

A player may now enter only letters and spaces for their handle. This
is to prevent abusive users from entering control characters.

Changed all \n to \n\r, to make the game usable with Falcon BBS.
This is because Falcon does not properly handle \n in a RAW: window,
\n\r should fix this. This change should not effect the way MafiaDoor
runs under DLG, since DLG properly handles both \n and \n\r, but if anyone
does have a problem, please let me know so I can fix it. Falcon sysops
should note that they will have to edit (or replace, but please keep my
name in there) the banner file to include \n\r.

***** Important *****
Added key files. Very few people register shareware, so this seemed like
a good idea. Sysops who register will receive a keyfile and the latest
version either via FIDO file attach, or via mail, if they include a disk
and postage. Future features in MafiaDoor will not work unless
you have the keyfile! Place the keyfile (mafia.key) wherever you have
Mafia: assigned.

The main display is now green if you are under protection, blue if you
are not, and red if you are in jail.

Players now only need to wait 23 hours to play when they run out of turns,
not 24 hours. This should lets people play at the same time every day.

Made internal changes to help with future modifications.

Added a Town menu. This will let players see the status of other players,
raise their popularity, or visit a consultant. The consultant is free
to players under protection, and is a good way for players to learn how
to build up their territories.

Other minor bug fixes and corrections.


>>>>>>>>>>>>>>>>>>>> Dec-03-91
Fixed bug where screen was not cleared before first page of news file
was displayed. The screen may now sometimes clear twice, but this is
fairly fast.

>>>>>>>>>>>>>>>>>>>> Dec-04-91
Fixed bug where cash was not updated when a player spread cash around town.

>>>>>>>>>>>>>>>>>>>> Dec-10-91

Popularity may now decrease each turn, just as bribes to the Mayor do.
I did this because it is now easy to buy popularity in town.

There is now a greater chance that a player will be found guilty when
they are framed.

>>>>>>>>>>>>>>>>>>>> Jan-20-92

Fixed Enforcer hits at location 0 in the newspaper function. This was due
to a Lattice function that was incorrectly documented, which resulted in
a null pointer.

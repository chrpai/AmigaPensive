                         MafiaEdit by Doug McLean
                         ~~~~~~~~~~~~~~~~~~~~~~~~

This very simple game editor for MafiaDoor will allow sysops to change
most of the defaults that a new player starts with. It will not allow
you to edit or view existing players (that wouldn't be fair). The only
item that may be changed that effects all players is turns per day.

To use MafiaEdit, you must have registered your copy of MafiaDoor. It
will not work on un-registered systems.

MafiaEdit is NOT designed to run under DLG, it is intented to be run
from a CLI or shell. All commands and input values must be followed by
a return.

To use MafiaEdit, simply run the program. It will look for the data files
wherever Mafia: is assigned. If they arn't found, they will be created.
If you wish to start a new game, delete mafia:#?.data and then run the
editor.

If the data files are found, then the record that contains new player data
may be edited. You may wish to increase various values as the game
progresses so that new players will have a chance.

All menu items are self explanitory and will not be described here (I don't
really like writing docs, and you probably don't like reading them). All
values entered must be greater than 0, if you select an item and decide you
don't want to change it, simply enter a 0.

Some items may not be increased past a certain point, if you make a change
and the item isn't changed, the value entered was probably too big (or
less than 0).

Turns/day must range between 4 and 20, but around 5 is best.

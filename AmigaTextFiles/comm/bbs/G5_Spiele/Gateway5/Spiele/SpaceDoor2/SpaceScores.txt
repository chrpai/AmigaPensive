                               SpaceScores
                -------------------------------------------
                A Player Score File Generator For SpaceDoor
                     Copyright (c) 1991 by Doug McLean
                -------------------------------------------

  SpaceScores will automatically generate a text file called
SD-Scores, placing it wherever Space: is assigned. You should
add a menu item to use DF to display this file. The file
contains the score for each player, the number of sectors
that they own, and their tech level. Scores are computed
as follows:

        1000 * Sectors Owned
      + Cash
      + 1000 * Tech Level
      + 50 * Discoveries
      + 1000 * Battles Won
      + 10 * Times Played
      + 50 * Number Of Holds
      - 100 * Damage
      -----------------------
      = Score

  SpaceScores may be run from the CLI, or you may wish to get
TPTCron to run it at set times. Also, you might wish to put
SpaceScores on the same menu as SpaceDoor (in my case, a seperate
SpaceDoor menu), to allow players to re-generate the scores file
after they play. If you do place SpaceScores on the menu, answer
Yes to "Reload Menu" and "CR/LF", and no to everything else when
you configure the menu entry. SpaceScores must be allowed to
complete running uninterrupted.

  Also, you may wish to generate a short sector report with
SpaceEd, and place it online for users too (using DF). If you
generate this file to Space:SD-SpcRpt then it will be automatically
deleted next time you re-create the galaxy (as will SD-Scores and
all the SD-#? player message files).

  You can decide before you start a game of SpaceDoor what score
will be required to win the game, and use the scores file to
determine who has won. Or you might wish to restart the game
every month (or whenever), the victor being the player with
the highest score at the end of the set time period. You can
set whatever rules you wish!

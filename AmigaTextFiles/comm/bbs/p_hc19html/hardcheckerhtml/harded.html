Der Online-Konfig-Editor

    Der Online-Konfig Editor dient dazu, den Checker in einigen Bereichen den Wünschen des Sysops entgegenzukommen

    Die Benutzung ist dabei relativ einfach. Alle Einstellungsmöglichkeiten sind auf 4 Seiten verteilt die mit den Tasten 1-4 erreicht werden können.

    Innerhalb dieser Seiten können die Funktionen mit en links in Klammern ([]) stehenden tasten geändert werden. Es wird zu fast jeder Funktion ein kurzer Hilfetext angezeigt.


    Funktionen Seite 1 (Checker Prefs):

    Taste Funktion Beschreibung
    A Minuten pro Upload hinzu Hier geben sie die Anzahl der Minuten an, die der Uploader pro Upload gutgeschrieben bekommen soll.
    B Sekunden max. auf Taste warten Wie lange soll nach dem Check auf eine Taste vom User gewartet werden?
    C .readme wenn keine File_ID vorhanden Soll eine eventuell vorhandene FILENAME.readme Datei (AmiNet Format) aus dem Archiv als File_ID.DIZ genommen werden wenn sich keine FILE_ID.DIZ im Archiv befindet?
    D Def. _ID wenn weder .readme noch File_ID Soll die Default File_ID.DIZ genommen werden wenn weder eine FILENAME.readme Datei noch eine File_ID.DIZ im Archiv vorhanden sind?
    E No Doublecheck Bretter Edit Öffnet den PMBS Editor zum ändern der NoDouble.dat
    (Kein doppelcheck in bretter)
    F No Doublecheck Gruppen Edit Öffnet den PMBS Editor zum ändern der NoDouble.group
    (Kein doppelcheck für gruppen)

    Funktionen Seite 2 (Filecheck Prefs):

    Taste Funktion Beschreibung
    A Viruschecker und Pfad Hier geben sie den Viruschecker und dessen Pfad an.
    Wollen sie keinen Viruscheck, wählen sie .
    Wenn sie einen der Viruschecker (VirusZ oder VirusCheckerII) gewählt haben öffnet sich entweder ein FileRequester oder ein Eingabeprompt in den sie den Pfad angeben müssen.
    B Werbefiles Datafile Hier geben sie die Datei an in der sich die Pfade zu den Werbefiles befinden die in die Archive gepackt werden sollen.
    Bei dieser Datei handelt es sich um ein Textfile mit folgendem Inhalt:

    -----8<-------
    Pfad:Filename
    Pfad:Filename
    --------8-----

    Der HardChecker wählt dann zufällig ein File aus und packt es in das Archiv.
    C Werbefile Modus Diese Funktion ist zur Zeit noch nicht Integriert!
    D .mp3 auslesen mit Hier können sie auswählen womit mp3 Soundfiles File_IDs erstellt werden sollen. Zur Auswahl stehen MP3info und MPProSP.
    E, F, G Defekte Uploads/Doppelte Uploads/Virulente Uploads Hier geben sie an ob die jeweiligen Uploads gelöscht oder kopiert (H) werden sollen.
    H Pfad zum verschieben Hier hin werden die Files kopiert wenn sie bei E,F,G kopieren gewählt haben.

    Funktionen Seite 3 (Adder Prefs):

    Taste Funktion Beschreibung
    A Keine Werbung in Brett Edit Öffnet den PMBS Editor zum ändern der NoAdd.dat
    (Keine Werbung in die Archive des jeweiligen Brettes)
    B Def. File_ID Hier geben sie die Default File_ID.DIZ an
    C Editiere Def. File_ID Öffnet den PMBS Editor zum editieren der Default File_ID.DIZ
    D Readme als F_ID in Archiv Soll eine aus einer FILENAME.readme datei erzeugte File_ID als File_ID.DIZ in das Archiv gepackt werden?
    E Def. SentByLine Editieren Öffnet den SentByLine editor. Hier können sie eine SentByLine erstellen die diejenigen User bekommen die selbst noch keine eigene erstellt haben.
    F SentByLine Aktiv Schaltet global für alle User die SentByLine ein oder aus

    Funktionen Seite 4 (Protokolle):

    Taste Funktion Beschreibung
    A, B, C Doppelte / Defekte / Virulente Uploads Hier können sie das jeweilige Protokoll lesen oder löschen

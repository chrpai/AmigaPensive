Dialog:
~~~~~~~
Möchte  der  User  mit dem Sysop sprechen, so kann er diesen Befehl aufrufen
und  warten bis der Sysop angelatscht kommt.  Beendet wird der Chat mit drei
punkten  in  einer  neuen  Zeile  '...',  Control-X  oder  wenn  der Connect
zusammengebrochen ist!

Hierbei gibt es drei verschiedene ChatArten: 

DoubleChat          -> Der Sysop tippt in der oberen und der User auf der
                       unteren hälfte.
LineChat            -> Der Sysop hat seine Zeile und tippt solange ALLEINE
                       bis er mit einem zweimaligen Return die Zeile an
                       den User übergibt.
AmiExChat           -> Eine ChatArt für /X-Fetischisten. Der Sysop tippt
                       genauso wie der User auf dem Bildschirm herum aber
                       in unterschiedlichen Farben (wer's haben muss...)

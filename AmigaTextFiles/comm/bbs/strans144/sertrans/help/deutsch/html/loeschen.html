Delete:
~~~~~~~
Der  'Delete'-Befehl  ist  einer mit der wenigen die sich abschalten lassen.
Dabei  kann  man  auch hier ein Wildstar angeben ('*').  Gibt man nun in der
Ebene  'Loschen  *'  ein  so wird alles in dem gerade befindlichen Directory
gelöscht!    Ansonsten  muss  kann  Filename  (auch  mit  angestellten  '*')
angegeben werden.  Dieser Befehl hat natürlich auch eine Sicherheitsabfrage!

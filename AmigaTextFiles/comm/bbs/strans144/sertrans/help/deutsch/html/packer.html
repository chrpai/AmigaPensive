Packername..........:         -> Den Namen des Packers.
Packen..............:         -> Hier wird ein String eingegeben in der
                                 Form wie man ein File zu einem Archive
                                 packen möchte.
Entpacken...........:         -> Das gleiche noch einmal zum entpacken
Auflisten...........:         -> Hier kann dann noch ein String zum auflisten
                                 des Archives eingegeben werden
Endkennung..........:         -> Die Endkennung, d.h. z.B. .LHA oder .DMS
10-Byte-Erkennung...:         -> Die ersten 10 Bytes des Files. Auch hier
                                 können platzhalter eingesetzt werden.
                                 '?' für ein Zeichen und '*' für alle!
                                 Für LHA z.B. ??-lh?-*

Für das Packen, Entpacken und auch Auflisten gibt es folgende Platzhalter:

{A} -> Das Archive                -> A wie Archive
{U} -> Das ungepackte File        -> U wie ungepackt
{Z} -> Das ZielVerzeichnis        -> Z wie Ziel

About the files:
~~~~~~~~~~~~~~~~

  Mostly they are just #?.h, #?.c and smakefile. Pretty self explainatory,
  although some of the programs may require you to create a GST file.

  The #?.gui files found in this archive are saves from GadToolsBox.

  The include.lha archive contains non-standard includes that you should
  stick in your SC:Includes/ directory.



WTF is recstring?
~~~~~~~~~~~~~~~~~

  El-Lame-o string encryption program used for the version string inside SX.

  type:
  	recstring sx/ver.txt

  and it'll create a text file in RAM: which you can insert at the top of
  SX/SX.c.

  .... But this is not necessary.

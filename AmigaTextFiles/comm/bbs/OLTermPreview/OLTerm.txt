
                          Off-Line Terminal Previews
                       --------------------------------

OLTerm is a new Off-Line-Terminal. It can be used to connect your Amiga
to any BBS running under MAXsBBS. It will allow you to write your messages,
to tag desiderated files, to view BBS stats as user lists etc. When you
done you can connect to your favourite BBS. It will send to BBS all your
messages and it will receive all new messages. If you tagged some files
you'll download them. If you want to upload some files it will upload
them. OLTerm, furthermore, updates file list at each connect, so you'll
filelist always automatically updated. Shortly: OLTerm minimizes calls
time!

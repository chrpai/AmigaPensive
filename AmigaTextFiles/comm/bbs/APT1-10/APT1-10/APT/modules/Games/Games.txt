%TC=6.
          An Example Menu where you can set-up some game doors.
          ====================================================

%TC=7.
 An example entry to run the CLI door "KNOT" is given below.

%TC=3.     XREXX.{{'RUNEASYDOS' "%RAW. %CRLF. DOORS:KNOT/KNOT %UNAME."}}
%TC=7.
 As you can see, its a very simple process to run a program from the ACD
 Driver menus!

 NOTE: The first X in the XREXX word above needs to be replaced with a
       Control/X character to make the command active. I used a Plain X
       as I did not want this information file to actually start-up the
       KNOT game! - It's part of the power of the ACD system that you can
       have ACD commands embedded in text files like this.

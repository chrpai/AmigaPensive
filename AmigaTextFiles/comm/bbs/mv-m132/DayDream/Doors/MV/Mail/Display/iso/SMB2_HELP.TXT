.------------------=[ SelectMessageBase HELP MENU ]=--------------------------.
|                                                                             |
|  - press cursor UP/DOWN key to move marker up/down                          |
|  - press '9' for page up                                                    |
|  - press '3' for page down                                                  |
|  - press '7' for home page (first page)                                     |
|  - press '1' for end page (last page)                                       |
|  - press 'RETURN' to tag/untag message base                                 |
|  - press 'A' to tag all message bases                                       |
|  - press 'N' to untag all message bases                                     |
|  - press 'T' for toggle on/off all message bases                            |
|  - press 'P' to switch All/Personal all message bases                       |
|  - press 'Q' to go back to previous SMB menu                                |
|                                                                             |
|    FLAGS                                                                    |
|     '-' you don't have access to that message base                          |
|     'A' download all messages from this message base                        |
|     'P' download only personal, addressed to you, messages                  |
|     'F' this means that this message base is forced ON and you can't turn   |
|         it OFF.                                                             |

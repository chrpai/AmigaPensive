Right, well you're probably wondering what's in this small archive.
Well basically two great doors to add on to a TransAmiga BBS system,
and the latest information on where to register TransAmiga, the best
shareware Amiga BBS Software around.

========================================================================

TAE.lha      = TransAmiga Everything! 
               A marvel of modern TA technology, displays over 40
               pieces of user and system information on one ANSI screen,
               still with enough room for a nice access bar.
               Very colourful and useful, have it as a door or in the
               Logon.trans.

TANLS.lha    = TransAmiga Nodelist Searcher!
               You know the nodelist lookup script that comes with TA?
               Not very informative, is it? Just the basic name, sysop,
               phone number really. Well this one has a very colourful
               ANSI screen, and displays about 20 bits of info about
               any node you've got in any nodelist! How? By using
               'getnode' that comes with TrapDoor (not distributed with
               this for copyright reasons).. As long as you have a
               nodelist compiled using traplist.library and getnode,
               this will improve nodelist-looking-up by 500%!

TARegForm.UK = TransAmiga UK Registration Form
               On Friday August 25, 1995, the official registration site
               for TransAmiga changed. This file is the latest form with
               all the new details.

========================================================================

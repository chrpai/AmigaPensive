TransAmiga Trivia history file

v1.6 - 10/26/95

 - Cleaned up the code a bit
 - Made some cosmetic changes
 - Added a submenu from the "V"iew High Scores. "C"urrent High Scores and a
   "L"ast Month High Scores.
 - Due to the above change, "R"eset High Scores now renames the file to
   HighScores.old, which is used for the Last Month High Scores.

v1.5 - 10/15/95
 
 - finally corrected the bug in 1.4a
 - added a hidden option "T"ime. This allows the user to find out the amount
   of total online time, time used today and time left today.  

v1.4a - 10/4/95

 - corrected a bug that caused 9 or more correct answers to get 15 minutes
   deducted (ZERO screen appeared) instead of adding time.

v1.4 - 9/20/95

 - fixed some minor cosmetics bugs
 - optimized the code somewhat
 - Added more question files
 - gave credit to the authors of the question files
 - found/fixed a small bug in the ZERO right code

v1.3 - 9/14/95

 - Added:(R)eset HighScores file
 - Added:(I)nstructions - How to Play
 - Added:****************************************************
         *BEWARE!! The game will DEDUCT 15 minutes from your* 
         *DAILY ONLINE TIME if you get ZERO answers right.  *
         ****************************************************
 - Optimized the screen displays
 - Minor logic bug fix
 - You can now get rid of the files "BBS:Extras/TaTrivia/INSTT" and 
   "BBS:Extras/TaTrivia/TITLET". They are no longer needed.

v1.2 - 7/18/95

 - fixed a bug that would cause the system to freeze if anything other
   than 1,2,3,4,Q were selected as the answer to a question

 - the game is now HOTKEYED
 
 - the HighScores file now holds the Top Ten Trivia winners instead of the Top
   Five.

v1.1 - 7/14/95 

 - fixed date display in HighScores.txt. It would only show up for the
   first person to make it into the HighScores file. (reported by Brian 
   Henderson)

 - corrected BBS:Extras/TATrivia/INSTT file. It said that the input was
   'hotkeyed'. Input is not hotkeyed. I started out meaning to make it that
   way, but it was to confusing to figure out. I forgot to change the INSTT
   file. (reported by Brian Henderson)

 - changed the way the program interprets the "answer" input. Hitting <CR>
   will simply do nothing until a valid option is pressed.

v1.0 - 7/12/95 

 - Fixed a bug that would appear to lock the game if the user played the 
   game to quickly and inadvertently hit a RETURN for the answer to a question.
   (reported by Brian Henderson)

 - rewrote most of the code to add a HighScores file and to speed up the
   output

v.01 - 5/26/95  - First release

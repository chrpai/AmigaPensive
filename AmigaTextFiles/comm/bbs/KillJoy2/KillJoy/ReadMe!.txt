Just a quick note for those of you who don't read docs :(

KillJoy as a default is configured for Zeus. IE: The user directory path
is set to BBS:System/Users/

You can change this to your own path depending on what BBS software you
run by running KillJoy either from the icon or from a shell with no args
and the gui will pop up for you to select the userdir gadget to point to
where your user directories are. This info is written to EnvArc:KillJoy as
you can see from the enclosed example with this distribution.

As you're probably not going to bother reading the docs before running it
anyway :) then may I just point out that you can edit the tooltypes of KillJoy
to select your preffered public screen and font now. Make sure it's an 8 point
font such as Topaz, or Pearl okay. It will look well strange otherwise, and
could crash your machine :( As a default KillJoy will use Topaz as that's in
your Rom.

You are running an Amiga, aren't you ? :-)

Comments and suggestions are most welcome. Please read the documentation for
full benefit from this handy little program. We've spent quiet a bit of time
writing it.

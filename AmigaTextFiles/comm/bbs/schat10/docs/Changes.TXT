Changes version by version

--------------------------------------------------------------------------
 0.3  -->  1.0
--------------------------------------------------------------------------

* It's now totaly configurable, everything can be positioned by you!
  (See SiCK-CHAT.CFG)

* Timer doesn't stuff up at midnight

* Colour letters/characters have a faster key return
  (If you hold down the key)

* Shell can be started from chat by typing "xShell"
  (SysOp only of course)

* Users can send files straight into chat.
  (Goes to default download directory as defind in daydream.dat)

* SiCK-CHaT can work without a macros file
  (If you don't want macros, just delete SiCK-CHAT.Macros)

* Minor word-wrap bugs fixed

* Better detection of carrier loss

* Colours defined in DayDream.DAT are used when entering line chat
  (CTRL-Z to enter line chat)

* TAB'ing now works.

* Function Keys feature added

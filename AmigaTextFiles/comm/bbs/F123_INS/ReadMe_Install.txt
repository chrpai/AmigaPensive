
Installation:
~~~~~~~~~~~~~
To install FAME extract the files F123_INS.LHA, F123_MAI.lha and F123_DOC.lha
into a directory you want to install FAME from.

Now start the installer script from workbench out of the directory you have
extracted the three files listed above to install FAME.

The file F123_DEV.lha has it's own installer script and musn't be installed
to run FAME.

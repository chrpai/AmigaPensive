SystemX - Frequently Asked Questions 1) Why doesn't the last callers ansi update? Firstly, you must have BBS: assigned to SX: To begin using the last callers program SAmiLog you must execute this in shell: "SX:Utils/SAmiLog -C" (this will create a storage file) Also make sure your sx:batch/logoff.bat file has the +s flag, ie: logoff.bat 342 -s--rw-d 26-Jul-97 13:09:55 ^ | ` Script flag If it doesn't, type this: Protect SX:Batch/LogOff.BAT +s 2) Why doesn't ToySent or other DayDream doors work? Type this in shell: "setenv dreamutils SX:Configs/" or add this line to your user-startup. 3) Why do I get a requestor to insert "FIFO:" ? Install fifo.library & handler! Grab it from AmiNet. 4) Why do shell doors or AED lockup/crash? You must give fifo a stack of 8192, in your startup-sequence: stack 8192 run NIL: l:fifo-handler stack 4096 (read the docs to FIFO.library for more information) 5) Why do uploaded files stay in FILES:FCheckX/ ? You must have a MOVE command in your C: directory. There is one included with System-X, which is a script. If it doesn't work, try typing this in shell (to make it a script): protect c:move +s EMail: zed@mentasm.com

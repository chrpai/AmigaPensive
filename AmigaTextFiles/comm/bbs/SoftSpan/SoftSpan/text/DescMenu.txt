 Soft-Span BBS Command Descriptions

ALIAS  - Alternate command names
BASES  - List available message bases
CD     - Select a download directory
CHAT   - Request chat with sysop
CONFIG - Set terminal configuration
DEL    - Delete message(s)
DIR    - List download directories
DL     - Download a file from the BBS
FB     - Leave feedback to sysop
GO     - Select a message base
HELP   - Help on use of the BBS
LIST   - List of download files
LOG    - Current user log
MAIL   - Send/Read electronic mail
MENU   - Display this menu
OFF    - Log off (leave) the system
PASS   - Change password
POST   - Post a message
READ   - Read messages
UL     - Upload a file to the BBS
USERED - Edit user accounts
VERSION- Version and serial number
?      - Main menu

Was ist Janus2?
---------------

Janus2 ist eine erweiterte Form des Janusstandards. Dieser neue Standard
basiert auf dem Prinzip des Batchup&Downloads.

Da bei diesem System viele kleine Einzelpuffer entstehen, geht das
Vorpacken deutlich schneller. Der Packer muss nicht erst das alte Archiv
umkopieren, dann ans Ende der Datei springen, weiterpacken und wieder
zurückkopieren. Er generiert einfach neue Archive. Das geht wesentlich
schneller.

Wenn zum Beispiel an eine Box 20 Einzelpuffer gesandt werden und nach der
10. Datei die Übertragung abbricht, werden die 10 schon übertragenen trotz
Abbruch schon einsortiert und werden auch nicht nochmal übertragen (grosser
Vorteil zu Janus)

Man kann im Janus2 Format Mails nach Ihrer Art getrennt anfordern. So kann
man z.B.:

NUR persönliche Nachrichten übertragen
NUR Brettnachrichten übertragen
ALLES übertragen
NUR selbst senden und nichts empfangen
NUR empfangen, aber nichts senden

So kann man z.B. einmal in der Nacht alle Daten holen und um aktuell zu
bleiben Tagsüber nur nochmal die PMS austauschen. So kann man (besonders
durch die neue Gebührenreform) gut Geld sparen.


Installation
------------

- tragen Sie unter Konfigurationen/Netzdaten ein neues Netzformat ein
  Netzname : JANUS2
  Kennung  : JANUS2*
  Directory: JANUS2

- Bitte legen Sie nun ein Directory "prometheus:netz/janus2" an

- dort kopieren Sie die Files CALLER,CALLED und SORTER bitte hinein


Wie trage ich eine Netzbox ein?
-------------------------------

- einfach GANZ normal die Box wie gewohnt eintragen

- es muß ein Packer eingestellt sein (NICHT UNGEPACKT!!)

- vorgepackt MUSS aktiviert sein

- Format auf JANUS2 stellen


Wie trage ich im Zeitplan den Call ein?
---------------------------------------

Ganz normal, wie unter JANUS

Wollen Sie aber die besonderen Funktionen Nutzen, geben Sie z.B. ein

CALL 0|CCASTLE|P
              
              ^^----- Moduskennung

|P	nur private Nachrichten austauschen
|H	Angerufener sendet nur Leerdatei
|M	Anrufer sendet nur Leerdatei
|N	nur Brettnachrichten werden ausgetauscht

bei nur CALL 0|CCASTLE (wie bisher) werden alle vorhandenen Nachrichten
normal ausgetauscht

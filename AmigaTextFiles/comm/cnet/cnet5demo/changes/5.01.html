Changes for v5.01
Click here  for information on upgrading to CNet/5.

NOTE: Your CNet/4 BBSLICENSE will not work with CNet/5. Contact us in IRC or by E-Mail  for a new license.

NOTE: After installation, you must login and "run" the CNet/C update executable "501" located in the update directory of the 5.01 distribution so that it can perform the migration described in change #4.

  1. Added new AWS section to CNet distribution archive.
  2. Added (modified since last release) AWS module cnetdir.library to CNet distribution.
  3. Added (unmodified since last release) AWS module cnauthbasic.library to CNet distribution.
  4. Migrated user FILES and WEB directories to a newly created HOME directory in user mail dir so that CNet's dirmaint (the "DM" command) and CINS can facilitate user access to these directories.
  5. CNet FTP now auto-adds, into the user select list, files received from remote sites.
  6. CNetIRC now auto-adds, into the user select list, files received via DCC.
  7. Fixed AutoSession® bug in which termination failure would occur if carrier lost while in LineEd/VisEd.

This is my BBSport1 file.  Followed by the SupraFax 14.4 modem settings.
_______________________________________________________________________

serial.device			<-- Device driver for this serial port
0				<-- Unit number
19200				<-- Waiting for call BAUD RATE
1				<-- LOCK  port at this baud rate?    (0/1)
0				<-- SHARE port with other processes? (0/1)
0				<-- PARITY on?  0==8N1, 1==7E1
ATZ				<-- Initialization string 1 (NO SPACES)
AT&Y0&K3			<-- Initialization string 2 (NO SPACES)
0				<-- Hang-up escape code (S2=x).  0==DTR drop
ATH				<-- Hang-up string
ATDT				<-- Dial-out string (for Auto-Validate)
ATA				<-- Answer string
ATM0H1				<-- Off hook string (for Local Mode)
ATV1E1M1			<-- Terminal mode string
30				<-- Seconds to wait for carrier (S7=x)
12				<-- 10ths of seconds between RING and ATA
RING				<-- keyword in modem's RING message
CONNECT				<-- keyword in modem's CONNECT message

Modem Settings:

Type AT&V to view your configuration.  Change settings to the following:

B1 E1 L0 M0 N1 Q0 T V1 W2 X4 Y0 &C1 &D2 &G0 &J0 &K3 &Q5 &R0 &SO &T4 &X0
S00:000 S02:043 S06:002 S07:050 S08:002 S09:006 S10:014 S11:095 S12:050
S18:000 S25:005 S26:001 S36:007 S37:000 S38:000 S44:003 S46:138 S48:007
S49:008 S50:255

THEN SAVE TO NONVOLATILE RAM

AT&W0 (saves to storage 0)

Serial Port Settings:

Using Workbench Prefs, set serial port to the folowing:

Baud Rate:  31250
Input Buffer Size:  65536
RTS/CTS  8,N,1

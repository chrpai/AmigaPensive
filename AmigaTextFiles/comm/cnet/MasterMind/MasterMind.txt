    Introduction.
    ~~~~~~~~~~~~~

 As you will probably already know, MasterMind is a game in which the player
 must guess a random colourcode. The player has ten guesses to crack the code.
 After each guess the computer will give you a hint that shows how close you
 were to the right colourcode.

 MasterMind maintains a list of the ten highest scores. This score depends
 on the number of tries in which the right code was guessed and on the
 required time to do so.

 This game was originally written for Excelsior! BBS.


    Installation.
    ~~~~~~~~~~~~~

 The default-path where this door should be installed is pfiles:MasterMind/
 If you want to install it in a different directory then you will have to
 edit the MasterMind-script and change the 'path'-setting at the top of the
 script (make sure that the path-specification ends with a '/' or a ':' ).

 Now go to the pfiles section on your BBS and add MasterMind as a ARexx door.

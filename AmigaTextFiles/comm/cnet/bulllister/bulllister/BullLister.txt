                    Bull Lister Version 1.0  (21/03/99)
                    -=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-

                               Introduction!
                             -=-=-=-=-=-=-=-=-

Bull Lister Is Basicly A Replacement BBS Lister Pfile For CNET BBS. Its
Very Easy To Install, But Not Only Can You List Normal Dial Up BBS' You Can
Also List Telnet BBS' And Web Pages! This Version You Can Add And Edit
Entries, But As Of Yet There Is No Option To Delete Entries, If You Want To
Delete An Entry You Will Have To Do It Manually.

                               Installation!
                             -=-=-=-=-=-=-=-=-

Like Said Before Installation Is Very Easy, All You Need To Do Is Add It As
A Normal Arexx Program! Simple As That! If You Want To Add It To Your
BBSMENU Add This Line To The Bottom Of Menu 2; Available Everywhere

L | {#0 Pfiles:BullLister/BullLister.rexx}

Remember { Is CTRL-Q

Thats It!!

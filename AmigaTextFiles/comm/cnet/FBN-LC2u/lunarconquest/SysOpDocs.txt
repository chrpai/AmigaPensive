                         L U N A R   C O N Q U E S T
 
                                    V2.00+
 
                                  SysOp Docs
 
                                   16/10/96
 
Before using the Lunar Conquest program, you should run the LC-SetUp
program from Workbench.  If you haven't done that, go do it now.
 
Among other things, the LC-SetUp program sets the SysOp Password.  Unless
you set the password, you will not be able to use most of the online SysOp
utilities.
 
To access the SysOp Menu, when the Lunar Conquest V2.00 title screen comes
up and prompts you to press RETURN, enter `sysop' and press RETURN.  You
will be presented with a list of the options available.
 
1. Reset Lunar Conquest
 
This is fairly straightforward.  Once you have entered the SysOp Password,
the current game files will be deleted and the config files reset.
 
2. Delete A User
 
This will allow you to remove a user, if necessary.
 
3. Edit A User
 
You can alter a user's account with this function.
 
4. Delete The SysOp Message
 
This will delete the current SysOp Message, which shows up once you have
connected to the LUNA1 computer.
 
5. Write The SysOp Message
 
This will allow you to use the Lunar Conquest line editor to enter a SysOp
Message.  It will overwrite any existing SysOp Message.
 
6. Read Maintenance Log
 
The Maintenance Log contains imformation on each user, any access to the
SysOp Menu and the results of the LC-Maintenance program.  This is useful
for tracking those pesky hackers.
 
7. Delete Maintenance Log

If your log is getting too big, or you're tired of the old data, this will
delete the log.

8. Quit SysOp Functions
 
This will continue the Lunar Conquest program from the point you left it,
allowing you to take your turns as normal.
 
9. Quit Lunar Conquest
 
If you were just doing maintenance on the system, or (GASP) you don't play
Lunar Conquest, this selection will quit the program.

Description
XPK is an interfacing standard between application programs and packer 
libraries. Every XPK application program can pack data with any XPK packer.

Distributability
XPK is copyrighted, but freely distributable for non-commercial use. Some
parts of XPK have a different legal status, ie. PD, GPL or shareware.

This is the main part of the xpk distribution. In this archive are all the
files you really need.

How to install the files: Decrunching XPK archives you want to install into
ONE directory and double click Install icon in xpk_User directory.
You need at least Installer program version 42.9 to do that. Installer can
be found in Aminet (util/misc/Installer*.lha). Current version is 43.3.

NOTE: Starting with version 3.10 I (Dirk Stoecker) am the programmer of
xpkmaster.library. I continue the work of Urban Dominik Mueller and
Christian von Roques with their permission!

Changes to last release:
Added alien cruncher support through use of xfdmaster.library. Improved the
passwort requester a lot.

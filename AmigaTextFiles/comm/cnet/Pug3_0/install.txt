                         Installation Instructions


	The workbench sort command: This command sorts text files from 0-9
or a-z. This was not good as the high score list usually want the high
numbers on top. I found a sort replacement on aminet called lsort.lha which
I've included in this archive. Copy the command lsort to your c: directory.
This command allows the same commands as the original command with a few
more options, namely "reverse" sorting which this game uses. The game will
look for lsort in your c: path.


Updating from previous versions:

Copy all related files to the correct directories except the boxers
directory. This contains updated boxer files. This will allow you to
continue your present game without restarting. Avoid copying over files
that contain data for your old game such as;

hist
quote
ranking
retired
st.data
fightlist


New Installation:

Uncompress this file in Pfiles: directory. Follow the SysOp.docs
instructions in the SysOp directory.




To make the game run faster after updating;

Load the intro file into a text editor and delete the following lines;

29-42

Load the Box.maint file into a text editor and delete the following lines:

17-30

 These lines merely count the number of lines in the Joe Louis boxer file
to ensure it contains 48 lines. If it's less than 48 lines then it
initiates the update program. It will not hurt to leave it in only that it
will make this count every time the game is started.
